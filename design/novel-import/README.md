# 导入作品交互审核稿

打开 [index.html](index.html)。默认玄墨、完整小说、“选择导入内容”；工具区在产品窗口之外，可以切换步骤、合成资料、主题和窗口尺寸。

v4 交换选项形式：上方“从文件直接导入”使用普通复选框，下方“根据正文补全以下内容”使用整卡可点击的卡片。补全列表默认全部显示，无展开/收起按钮；关闭补全总开关只禁用卡片，不折叠。两组选项各自保留选择，无正文时仍走仅拷贝路径。

v3 对齐软件已有分类：用“爽点/泪点”“文风”替代“其他设定”泛称，并与金手指保持独立。13类来源、12项补全均使用实际名称；在来源页点“添加文件”可纳入含爽点/泪点和文风的合成补充资料，查看识别后默认勾选与来源预览。

建议审核：来源核对 → 允许识别 → 内容识别中 → 多选与补全 → 确认导入并选择示意空目录 → 开始导入。识别中显示 AI 等待动画；点窗口外“完成合成识别”模拟回执进入选择。本稿不调用模型，正式实现由真实请求结果结束等待。选择页为单栏、无导入计划；补全卡片整卡点击，来源为普通复选框；计划在后续确认页展示。

点工具区“推进合成任务”推进导入进度；正文与已有角色设定场景会在年龄矛盾处暂停，可审核三类决策。正文修改必须先逐处勾选，再二次确认。识别/导入收起后，从原导入入口或任务条恢复；取消识别回到来源核对。

来源清单使用真实文件类型 SVG，素材来自 vscode-icons 官方仓库；[来源与版本](assets/file-icons/provenance.json)、[MIT 许可](assets/file-icons/LICENSE.txt) 随稿保存，全部本地加载。玄墨适配 Markdown 图标亮度，窄窗保留文件类型图标。

“只有设定”展示纯拷贝与来源之间的取舍；“只有正文”展示缺项补全；“未配置模型”展示仅本地拷贝路线；“读取异常”必须排除异常文件后继续。通过工具区直接跳到结果页仅用于查看合成完成状态，不代表前序操作在产品中已经执行。

本稿没有应用 IPC、网络、模型或真实文件访问；系统文件/目录对话框只做位置示意，模型设置与原业务面板衔接标明边界。所有文字和数字为本地合成资料。刷新重置，没有持久化，不应输入真实作品或 Key。

产品与审核记录位于 [docs/novel-import](../../docs/novel-import/README.md)。本稿尚待用户 UI 审核。之后才开展技术方案、定向用例、实现与定向测试。
