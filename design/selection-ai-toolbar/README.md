## 自检

`node design/selection-ai-toolbar/check-flow.mjs`（Node 24，需 playwright）在无界面 Chromium 中用真实鼠标拖选检查 63 项，结果全部为 true，无页面错误：

- 预览、编辑、分屏左侧、分屏右侧四处框选后，工具栏出现在选区下方 40 px 以内；点击外部关闭。
- 工具栏顺序：添加评论、输入修改要求、润色、扩写、续写、⋯；预览与编辑视图中点「添加评论」后工具栏消失、评论框聚焦、锚点为所选原文，Cmd/Ctrl+Enter 发表后评论卡片出现；评论框打开期间拖选不弹工具栏，收起后恢复；⋯ 菜单列出六项；Esc 关菜单保留工具栏。
- 点击「输入修改要求」后工具栏消失，输入框出现（宽 560 px、在面板内、位于选区下方）并获得焦点；窄面板时宽为正文宽 − 32 px；@ 弹窗与 chip 插入可用；两行要求中按 ↑/↓ 光标在行间移动、macOS ⌘↓ 两次高亮到缩写、⌘↑ 循环到总结、光标位置不变、Alt+↓ 不切换；Windows Alt+↓/↑ 切换、Meta+↓ 不切换；提示显示「⌘↑↓ / Alt+↑↓ 选择功能」；无 Enter 标记，默认高亮润色且 ↑/↓ 不改变高亮；Tab 聚焦润色、↓ 高亮移到扩写且提示变为「Enter 执行扩写」、首项 ↑ 回到输入框；没有作品选择和发送按钮；下方列出六项功能。
- 处理框位于底部；「重写中」→ 停止（无替换按钮）→ 继续 → 「重写完成」，框变高，按钮为放弃/替换。
- 重试：按钮顺序放弃 / 重试 / 替换；重试进入「重写中 · 第 2 次」，完成后出现不同的一稿，正文与版本历史不变。
- 替换改写正文，历史新增「AI 重写前」「AI 重写」；撤销恢复原文，并新增「撤销 AI 重写」。
- 「⋯ → 版本历史」中依次出现「撤销 AI 重写」「AI 重写」「AI 重写前」；「AI 重写前」详情正文等于替换前全文，「AI 重写」与之不同；可返回正文。
- 放弃后正文不变；处理期间原文被改动时替换被拒绝；无模型时功能按钮全部禁用；窄面板工具栏不超出面板。
