  XRef and Encrypt stop before PDFDocument.load. No fallback parser/decompression.

  ArrayBuffer with updateMetadata:false, ignoreEncryption:false,
  throwOnInvalidObject:true and ParseSpeeds.Slow. Actual raw stream contents
  share the source buffer, including a tested nonzero-offset source view.
- Raw PDFDict/PDFArray/PDFRef traversal uses explicit tree/parent/resource
  limits, complete reference checking, PDFNull preservation and fixed resource
  closure. No getPages/Resources/ascend convenience API, save, normalize,
  getContents/decode or pdf.getData is used by production proof code.
- The 20000 object/edge budget stops all later lookups; repeated immutable font
  dictionaries reuse their already validated closure proof. This is memoization
  of the same source object, not a relaxation of font/resource validation.
- LTR scalar correspondence requires complete non-layout sequence equality,
  homogeneous single-scalar U+22EF glyphs all carrying originalCharCode A1AD,
  valid actual font state, supported rendering state, no bidi/vertical/Cf/control
  or unpaired surrogate ambiguity. Exact UTF-16 offsets preserve every other
  character and all item/EOL whitespace. Page changes are atomic.
- Only actual corrections create sourceTextDecoding. The strict schema binds
  source/closure/glyph/correspondence hashes, before/after UTF-8 hashes and
  increasing offsets. Core validates final and inverse page digests, counts,
  page ranges, total size, proof hash and ledger/source binding.
- Pure-text corrected PDFs enter scope/plan/private publication audit despite
  having no raster image. Read-record and FileView expose only policy/page-count/
  changed-character-count summaries. Full proof remains private; no PNG/path.
- choose/reselect use current strategy. Legacy supplementation explicitly uses
  legacy and compares the temporary result before adopting any ledger. A text
  mismatch preserves old prose, units, working units, successful coverage and
  checkpoints, reports invalidation, and requires explicit re-selection.
- Preview still renders the original PDF.js glyph stream. Locked CMaps, original
