## 必须保留的问题

**D1-LN01，P1：关联与事件粒度没有闭环。** `narrative-00-xiaoxu` 至 `narrative-13-diary13` 的 `facts.refs` 逐个解析后都是 `[]`，合计 **0 条** 叙事到事件关联。没有错误 eventId 的报错并不等于实际关联正确：这里根本没有建立引用。`worldline-xiaoxu` 的 text 是探访/得日记/撮录的一段总述，`worldline-diary` 的 text 是整个病中日记的一段总述；虽然有两个明确 lineId，却没有把诊病、读史发现、劝兄、妹妹回忆及自我怀疑等主要转折形成可区别、可供对应叙事引用的事件内容。不能要求“每章恰一事件”或固定事件数，也不能拿两条名称加十四个章节编号声称完整事件/披露结构通过。后续需保留确证范围和多重叙述来源，在具体有据节点上关联，不能通过造客观吃人事件或随便把十四项全挂同一总述来补数。

**D1-LN02，P1：日记三后半核心转折在两线中缺漏。** `narrative-03-diary3` 只写街上女人的话、病者对眼色/笑的解释和陈老五拖回；sourceUnitIds 也仅为 U1 `[0,953)`。本章实际为 `[747,1571)`，后半 U2 还包括反锁书房、佃户告荒并转述村中挖食心肝、日记者由其言语推论自身危险，以及翻历史“仁义道德”字缝而见“吃人”的关键阅读转折。具体证据为正文 `[1026,1083)` 的佃户转述、`[1447,1454)` 的“这历史没有年代”、`[1467,1471)` 的“仁义道德”及 `[1501,1514)` 的“满本都写着两个字是‘吃人’”（原文为双引号）。当前 worldline-diary 总述也没有承载这组具体内容。别的类别可能保留了相关材料，但不能替代本两线的情节/披露覆盖。此项不是因为 quote 未命中，而是完整原章的重要后半未进入相应叙事与事件。

**D1-LN03，P2：两处时间措辞超出源证据。** `narrative-07-diary7.facts.temporalScope` 写“回忆前天街上男女与近日大哥作为”，原文 `[2687,2699)` 是“试看前几天街上男女的样子”，不是确定前天。前天在同章还用于狗的旧事，不能移到街上男女这一句。`narrative-06-diary6.name` 使用“黑夜中的……”，但其自己的 text/temporalScope 正确保留“昼夜不明”，原文 `[2579,2591)` 明说“不知是日是夜”；标题宜保持黑暗/昼夜未明，不应独自确定为夜间。这不改变日记序号，但有时间精确化问题。

**D1-LN04，P2：框架知识源与可靠性应一致。** worldline-xiaoxu 标“角色有限事实”，narrative-00 却标“客观事实”；两者都以余的小序作 attribution，但康复候补实际来自兄长对余的告知，余阅日记后的“迫害狂”判断则又是一层。narrative-00 的 text 确实写“以余的视角交代”，没有直接假造日记中发生候补，因此不能据一个 enum 就断言它已把全部叙述拍平成客观世界；但当前 metadata 不足以把框架消息当作已核实康复事实，应补清消息链并避免与有限视角标注相矛盾。这与角色报告 CS02 是同一跨产物归属风险，不另捏造新的事件。

**跨产物一致性仍失败。** narrative-10 正确写狂人“被大哥称为疯子”，而同一最终快照的 char-dage 仍写大哥“被称为疯子”、狂人“称其为疯子”。角色报告 CS01 的同一 P1 因而在终态同时存在正确叙事与错误 profile，不能把自动零 conflicts 解释为两者已一致。

## 全部两线字段与叙述层核对

两项 worldline 都只有 `lineId/lineName/timeKind/time/people/reliability/attribution/temporalScope` 这些当前字段：lineId 各对应本项，timeKind 均 unknown，没有强填日期或父级。小序 people 的三个值和日记 people 的十一个值共十四个引用全部指向本快照 character；没有姓名猜测、非角色 ID 或已知坏引用。小序 people 包括被谈及的病者，不能据此推导余探访时与病者当面相见；text 实际写“仅晤其一人”。
