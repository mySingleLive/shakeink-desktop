## ol-r3 失败与修复

模型在细纲 facts 里加了 `order`。车道细纲原先只过形状检查，严格的原生字段检查在接受回复之后才执行，抛出的错误不在可重跑类别，所以步骤直接失败。修复（`desktop/service/novel-import-ai.ts`）：车道细纲在回复 schema 里执行同一严格检查，并给出允许字段的纠正提示，因此会进入纠正轮；再失败则报“模型返回结构不完整”，按章拆分或重跑。用例 OP-16。r4–r6 共有 6 次 `lines-facts-reject {unsupported:["order"]}`，都在纠正或重做后完成。
