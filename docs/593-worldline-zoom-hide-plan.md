# 593 · 世界线时间线缩小后按重要度隐藏事件 技术方案与测试用例

来源：用户 2026-11-20 修改要求。基于 `4a01dbf`（docs/592）。

## 需求

| # | 内容 |
|---|---|
| H1 | 时间线：一般事件已改为时间点后，继续缩小到一定程度，一般事件彻底隐藏，画布只剩重要和关键事件的卡片 |
| H2 | 再缩小，重要事件先改为时间点（与一般事件的过程一致） |
| H3 | 再缩小，重要事件的时间点也隐藏，只剩关键事件的卡片 |
| H4 | 隐藏的事件不在状态行提示，也不计入“N 个…显示为时间点”（用户选择“隐藏后不提示”） |
| C1 | docs/592 已通过的功能不变；只作用于时间线画布，事件目录、事件表、小地图、图例计数不变；界面状态不写入作品 |

用户确认的顺序（2026-11-20 选项“一般先隐藏，重要再走一遍”）：

| 级别 | d（px） | 画布 |
|---|---|---|
| 0 | ≥ 160 | 原样 |
| 1 | 40–160 | 卡片缩小 |
| 2 | 10–40 | 一般 → 时间点 |
| 3 | 2.5–10 | 父事件自动折叠 |
| 4 | 0.6–2.5 | 一般隐藏（重要、关键为卡片） |
| 5 | 0.15–0.6 | 重要 → 时间点 |
| 6 | < 0.15 | 重要隐藏（只剩关键卡片） |

d 的定义、0.75 卡片系数、放大回差 ×1.15 都沿用 docs/592 §2.1。原级别 4（d < 2.5 时“重要”变时间点、一般时间点仍在）取消，由级别 4–6 替代。

阈值依据（真实作品 LOTM-587-wg-r1，`592/e8/result.json`）：复位视窗 d ≈ 0.11（跨度 1178 年）落在级别 6，画布只有关键事件（根事件中关键 58 个）；d 0.15–0.6 对应跨度约 220–880 年；d 0.6–2.5 对应约 53–220 年。按 ×1.2 的滚轮步进，每级约 7 步。

## 1 纯函数（`src/lib/planning/worldline-layout.ts`）

### 1.1 级别

```ts
export const ZOOM_HIDE_NORMAL = 2.5;   // 替代 ZOOM_KEY
export const ZOOM_KEY_POINTS = 0.6;
export const ZOOM_HIDE_KEY = 0.15;
export type ZoomLevel = 0 | 1 | 2 | 3 | 4 | 5 | 6;
const ZOOM_STEPS = [ZOOM_FULL, ZOOM_POINTS, ZOOM_FOLD, ZOOM_HIDE_NORMAL, ZOOM_KEY_POINTS, ZOOM_HIDE_KEY];
```

`zoomLevel(d, prev)` 的写法不变（按阈值个数计级，回差规则对新阈值同样生效）。`cardScale` 不变（级别 ≥ 1 且 d ≤ 40 时为 0.75）。

### 1.2 门槛

```ts
/** hide：重要度低于它的事件隐藏；bar：低于它的画成时间点；pointClass：时间点的重要度类别（1 一般 / 2 重要，0 无时间点）。 */
export function zoomBars(level: ZoomLevel, maxImportance: number): { hide: number; bar: number; pointClass: 0 | 1 | 2 }
```

| 级别 | hide | bar |
|---|---|---|
| 0–1 | 0 | 0 |
| 2–3 | 0 | 2 |
| 4 | 2 | 2 |
| 5 | 2 | 3 |
| 6 | 3 | 3 |

- `hide = min(hide, maxImportance)`：`maxImportance` 是世界线中已定位事件的最高重要度（按图例筛选后的树，docs/591）。没有关键事件的世界线在级别 6 不隐藏重要事件，没有重要和关键事件的世界线永不隐藏。画布不会因为隐藏而整片变空。`bar` 不封顶，保持 docs/592 的时间点行为（例如全是一般事件的世界线在级别 2 起仍是时间点）。
- `pointClass = bar > hide ? min(bar − 1, maxImportance) : 0`。

### 1.3 `zoomPlan`

`ZoomPlan` 新增 `hidden: ReadonlySet<string>`。规则在 docs/592 §2.2 上增加：

- 事件“显示”（卡片或时间点）：重要度 ≥ `hide`；或在 `keep.cards` 中；或是 `keep.cards` 中某事件的祖先；或有子孙满足。否则隐藏。
- 事件画卡片：在显示的前提下，沿用 docs/592 规则（重要度 ≥ `bar`，或 kept / 祖先，或有子孙是卡片）。`showAll` 时 `bar` 视为 `hide`（时间点改为卡片，隐藏的仍隐藏）。
- `walk` 先判隐藏：隐藏的节点加入 `hidden` 并停止下探（子孙随它不画、不计）；再判时间点；再判自动折叠（级别 ≥ 3）与用户折叠。`hidden` 只含最上层的隐藏节点。
- `points`、`autoFolded`、`hidden` 与 `prev` 内容相同时沿用 `prev` 的对象。

例：一般父事件带一个重要子事件。级别 4：父事件因子孙显示而显示，子事件是卡片，所以父事件是卡片并自动折叠（层叠卡）。级别 5：子事件不再是卡片，父事件画成时间点（`▸ N`），计入“重要事件”时间点（它代表一组重要事件；计数含它）。级别 6：父事件与子事件都隐藏。

### 1.4 布局

`FamilyOptions` 与 `TimelineInput` 新增 `hidden?: ReadonlySet<string>`。`buildFamilies` 跳过隐藏的根，`visibleKids` 过滤隐藏的子事件。`EventTimeline` 的 `relayout` 输入加入 `plan.hidden`。

## 2 `EventTimeline.tsx`

- `maxImportance` 按 `tree` 记忆；`bars = zoomBars(level, maxImportance)`。
- `showAll` 状态改为记录点击时的时间点类别：`showAllRaw: 0 | 1 | 2`。生效条件 `bars.pointClass > 0 && showAllRaw === bars.pointClass`；layout effect 中类别不同就清零（从“一般时间点”缩到“重要时间点”时，“显示为卡片”不延续）。按钮切换 `showAllRaw` 在 0 与当前类别之间。
- 状态行提示：`pointClass > 0 && (points.size > 0 || showAll)` 时写入 `{ count, important: pointClass === 2, showAll }`，否则写 `null`。级别 4、6 通常没有时间点，提示消失。
- 文字（`ZoomNoteLine`）：`N 个一般事件显示为时间点` / `N 个重要事件显示为时间点`；`showAll` 时 `一般事件已显示为卡片` / `重要事件已显示为卡片`，按钮“显示为卡片 / 改回时间点”不变。原“一般和重要事件”文案删除。
- `ZoomNote.key` 改名 `important`（`worldline-viewport.ts`）。
- 小地图、事件目录、事件表不读 `plan`，不变。滚轮锚点事件被隐藏时不做纵向跟随（与锚点在空白处相同）；真实应用验证检查全程无“视图内没有事件”，出现再处理。

## 3 已知限制

- 级别 ≥ 4 时用户手动展开（`unfolded`）一个家族，若子事件全部隐藏，父卡仍画成层叠卡（有子事件但没有画出）。
- 被隐藏的事件仍可从事件目录、搜索定位：定位会选中它，选中的事件总是卡片（docs/592 `keep.cards`）。
