# 中转兼容性修复验证记录

日期：2026-10-24；基线：`3162a4f13dab6aa94d2a2a46061edf0f36fcc9a2`。

## 修复范围

- 配置测试和实际生成共用根地址规范化：仅自定义 OpenAI 文本模型的根路径在请求时补同源 `/v1`，持久化端点和凭据作用域保持原值。
- 自定义 OpenAI 文本模型可明确选择 `auto`、`chat` 或 `responses`。旧记录缺字段等价 `auto`；新建界面默认 Chat。配置测试与生成共用策略，不在失败后自动切换 API。
- 显式自定义接口不继承官方同名型号的附加能力；显式 Chat 同时关闭 SDK 按官方型号推断 reasoning 的行为，保留 `system` 角色与通用预算；Responses 保留 `store:false`。
- 流式文本请求检查 SSE 类型；共享模型层校验有效正文或合法工具调用及正常结束，拒绝 HTML、空流、仅推理与异常终止。取消、授权撤销和原始错误优先，部分正文保留。
- 作用域变化后明确重输相同密钥可正常提交；未重输仍不能跨作用域复用。切换接口保留同作用域密钥，增加授权修订并撤销旧执行。
- HTTP 401/403 经主进程、服务传输、SDK 和聊天落为固定认证/权限提示，不回显供应商正文，不自动重试；取消、授权撤销和额度分类保持优先。用量快照记录所选 `wire`。

方案与用例见[首轮方案](../design/2026-10-24-relay-compatibility-fix.md)、[首轮用例](2026-10-24-relay-compatibility-cases.md)、[补充方案](../plans/2026-10-24-explicit-relay-api-design.md)和[补充用例](2026-10-24-explicit-relay-api-cases.md)。

## 真实 macOS 验收

本机 Ad-hoc 测试构建可以加载已有工作台、作品与模型。原生菜单退出后进程结束，重开可以恢复会话；程序与保存新字段前的加密配置均保留私有恢复点，未迁移或覆盖用户作品。

真实中转公开目录只为选定型号声明 Chat Completions。界面明确选择 Chat 并保存后，最小连接测试和新短会话仍被上游拒绝；聊天显示固定权限诊断，未产生非空回复。失败会话退出重开后保留明确错误，没有“生成中”残留或误成功。接口选择已持久化，原加密凭据、端点和型号保持相同。

最小连接测试直接经主进程发送有限预算的普通非流式请求，绕过聊天 SDK，未附带工具或官方型号专用参数。当前证据不能进一步区分中转资源授权、分组路由或前置 WAF/IP 等限制；具体上游拒绝原因待服务方核对。公开模型目录不证明当前 Token 具有调用权限。

**软件修复已完成，真实供应商连通尚未验收通过。** 本记录不将外部拒绝推定为密钥错误，也不将合成测试或原生启动替代成功生成。

## 验收与回退边界

- 真实密钥、用户正文、完整配置及本机恢复路径不进入源码、日志或公开证据；仅记录脱敏状态。界面主动操作次数不等同于抓包确认的实际 HTTP 次数。
- 包装测试的两项固定历史损坏样本本机缺失，未伪造样本或改动断言，不计通过。未执行全套浏览器、Windows、真正断网首启或正式签名/公证发布验收。
- 当前包为本机 Ad-hoc 测试构建，未公证；没有更改 Gatekeeper、全局网络或应用沙盒设置。全仓正式验收状态不提升。
- `wire` 为可选字段，旧配置无需迁移；旧版 strict Schema 不识别新字段。保存后回退旧程序须配套恢复对应旧配置，单独换回旧 app 不构成完整回退。
- 原配置导入导出仍只迁移角色引用，不扩展为跨机复制模型授权或接口配置。
