## 核对与必要细化

- **SI-01** 应断言没有 `<semantic-native-contract>`、其它阶段输出合同及 Scene entityType/facts 的原生结构要求；允许提示明确写“不能使用 parentId”，不要把禁止错误字段的提示文本本身当作失败。冻结 scene 以外的 roster、普通 analyze、entity、review/reconcile、touches 提示基线。保留不执行来源指令、真实原文名称/别名、未知父级省略、无条目返回合法空 roster 的约束。
- **SI-02** 使用真实生成桥的合成 generateText，分别覆盖根数组、根额外键、缺 roster；parent:null、空串、错误 parentId；合法空清单和省略 parent。永久错误恰好两次生成，重试成功恰好两次。错误诊断不显示未知路径键、值、Zod反馈或敏感哨兵；根级空路径也必须是“响应结构”等固定标签。网络/授权一次、取消零或至多原进行中的一次，均不能因新增场景诊断被转换成可重试结构错误。
- **SI-03** 12个以上候选在现有4路实体并发和8项提交门下能覆盖多批。应以实际 journal 断言第一批子节点先落盘，后续实体请求仍发生，不能只用延时猜测。最终每个候选 ID/name/kind 唯一对应完整 artifact，保存 text、facts、证据与有效父引用，所有done任务身份一致，不能仅比较计数。该例证明现有算法可行，不预设需要更改提交算法。
- **SI-04** 将错父级、循环、伪造证据、未知单元分别独立构造，避免负例被另一个错误抢先拒绝。补充合法前向父级作为正例，证明没有一概删父引用。沿用现有容量与严格语义校验，不必为了无变化路径新增镜像测试。
- **补充 SI-05（必要）**：controller roster 多批运行中，一批结构失败、其它已完成批保留。确认失败请求的单元未获 coverage，成功批 stash 与 coverage 落盘；经正式“重新识别”动作恢复，只请求缺少覆盖的单元，原已覆盖单元不重复请求，最终全部单元覆盖且已有/新增条目合并正确，错误被清除；不注入 journal 成功、不清空 stash。如重启恢复也会用在真实验收，应通过 fixture 的实际 close/initialize 路径验证原生持久化恢复。
- **SI-REAL** 范围与预期分明。正常 UI 选择仅推断场景并保留全1402章，可以验证场景全链路而避免把其它类别未执行说成成功。数据库重开核对须记录实际模型识别全部候选、独立场景记录、父级、完整业务字段及正文一致性；模板式空字段/非空计数不替代完整内容对照。文学地点识别的穷尽性另做实际抽查，不以全单元 coverage 直接推出。

本审核为测试设计审核，尚未运行新增测试或真实模型；TDD RED、GREEN 和真实验收应分别留下证据。

## R5与SI-08场景entity用例审核

## R6与SI-09明确协议扩展用例审核

阅读SI-09新增用例，**补充设计通过，可开始RED**。本次明确扩展覆盖上一节“不暗扩scene v2”的边界：仅scene entity按编辑器已有schema2四文本字段接受并早期验证，其他阶段仍保持。

必要检查：

- schema、真实生成桥与controller→runImportAi链路均覆盖严格编号和合法直接引文；serialized payload显式optionIndex正确，输入选项本身来自原units；sourceUnitIds由证据派生且保留合法已声明单位。缺省/外部/实体ID等机械字符串声明配合法证据可归一，但外部evidence.unitId、坏quote、越界/小数/字符串索引、索引混合直接引文键等必须拒绝。
- 四个schema2文本字段均有非空合成值，text/父级/evidence/合法sourceUnitIds逐值保存。未知native键、非法字段类型、错目标与错父级必须在生成schema进入已有结构纠错，而不是生成成功后才在最终服务门突然失败；root无parent仍合法。
- 按每个候选ID统计请求/生成：前两轮非法后第三轮有效应恰好2请求/3生成；持续非法恰好2请求/4生成后该任务失败，不能用宽松上限正则或全批总数掩盖多试。结构和anchor各至少一例，正常其它候选不能被测试夹具误计为该目标调用。
- 网络/授权/取消/预算/持久化错误原类传播、每目标不增加请求；真实磁盘保存barrier已有scene SI-07可复用，若仅从AI边界注入“磁盘错误”字符串，只能声称错误分类测试，不能写成实际磁盘故障验收。
- world/item/普通scene analyze不获得索引协议、来源派生或schema2四字段；角色原协议/提示hash/模型策略保持。新增scene提示需准确描述索引/直接形式及原生字段，父级与事实不能由本地修正。

本审核不以SI-09的合成恢复测试认证任何真实书稿内容或整书成功。
