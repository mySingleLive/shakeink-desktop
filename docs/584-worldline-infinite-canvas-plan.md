## 方案（修订 3，回应 584 审核 1–9、复审 N1 与建议）

### R1 无限画布

- **store**：`ViewportWindow` 增加 `y`（px，任意有限实数，默认 0）。`check` 与等值判断包含 `y`。符号沿用现有约定：`y = −scrollTop`，即 `y` 增大时内容下移。`TimelineTreeNav` 订阅时只在 start/span 变化时更新（比较后跳过 `y` 变化）。
- **车道**：`overflow: clip`（不是 hidden：hidden 元素在 focus / scrollIntoView 时仍会被浏览器滚动）；另在 `scroll` 事件中把 `scrollTop`、`scrollLeft` 归零作为兜底。平面 transform 为 `translate(x, y)`。时间线根节点暴露 `data-view-y`、`data-view-start`（精确值，供测试；583 审核建议 4）。
- **所有纵向写入改为 `setWindow({ y })`**：
  - PlanningWorkspace：`windowY` ref 删除，`setWindowRange` 的 `y` 直接写 store；`:2055`（Esc 恢复）、`:2190`（视图记忆恢复）、`:2269`（locateWorldEvent）、`:2368`（locateEvent）、`worldViews` 保存时取 `getSnapshot().y`。
  - EventTimeline：`:261`（⌘/Alt 竖移）、`:303`（缩放锚点：改为 `y += 卡片新 top − 旧 top`）、`:307`（`restorePan`）、`:401/:417`（平移起点与移动）、`:331/:335`（vband 改按 `−y` 计算，监听 store 而不是 scroll；仍按 step 取整，只在跨过 step 时 setState）、方向键 ↑↓。
- **打开居中**：store 增加一次性请求 `requestCenter()`；PlanningWorkspace 只在 fitted 分支（`fittedViews` 首次、根层级，`:455-472`）发出；`EventTimeline` 在下一次打包完成后的 layout effect 中消费：取视窗内已打包卡片（`step.elements` 的 card）的像素包围盒，横向令其中心对准车道中心（改 start），纵向：高度 ≤ 车道时垂直居中，否则 `y = 24 − top`。**定位优先**：深链、`pendingLocate`、目录 / 搜索定位发起时取消未消费的居中请求。视图记忆恢复不发居中请求。
- **无边界**：`y` 与 start 都不夹取。
- **拖丢恢复**：没有任何卡片在视图内时，车道中央显示“视图内没有事件”与按钮“复位”（与工具栏“复位”同一动作：fit + 居中）。不加网格背景（审核建议，YAGNI）。

### R2 指针与键盘

**分派**（时间线根节点 `[data-timeline]` 的 `onPointerDownCapture`，先于卡片标题、时期色带与边缘处理；时期行 `periodsRow` 是车道的兄弟节点，所以挂在根节点而不是车道上 [复审 N1]）：

| 按下 | 位置 | 行为 |
|---|---|---|
| 中键 | 任意 | 平移；`preventDefault`（阻止 Windows 自动滚动、Linux 中键粘贴）+ `stopPropagation` + 根节点 `focus()`；车道 `onAuxClick` 阻止中键点击触发卡片内链接 |
| 左键 + 空格已按住 | 任意 | 平移（同上，不 preventDefault） |
| 左键 | 卡片标题 / 时期色带与边缘 | 改时间拖动（现有逻辑）。卡片标题（EventCard.tsx:171）、时期色带（EventTimeline.tsx:374）与两个边缘按钮（:381、:389）的处理器都加 `button === 0 && !space` 判断 |
| 左键 | 其他位置（含卡片正文、空白） | 移动 < 5px 松开 = 单击（卡片上：选择；空白：清空选择）；≥ 5px = 框选 |

**焦点**：左键单击卡片或空白处、框选结束、中键按下后，都对时间线根节点执行 `focus({ preventScroll: true })`（目标是卡片内按钮 / 输入控件时除外），保证空格、Delete、方向键生效。

**空格**：在时间线根节点上 `keydown`（目标不是 input / textarea / select / button / contenteditable / `[role=button]`，且 `!e.isComposing`）时 `preventDefault` 并记 `space = true`（忽略 `e.repeat`），`keyup` / 失焦时清除。焦点在卡片内按钮上时空格按原生行为点击按钮，不进入平移（审核 9）。按住空格时车道 `cursor: grab`，平移中 `grabbing`。

Esc、失焦、pointercancel：平移恢复 start 与 `y`；框选取消且选择不变；改时间取消（现有）。

**选择**：
- 新状态 `selection: ReadonlySet<string>`（PlanningWorkspace），与 `eventSelection`（主选中：详情按钮、目录高亮、卡片 `selected` 外圈）并存。所有选中卡片显示 `data-selected` 外圈。
- 单击卡片：`selection = {id}`，主选中 = id。⌘/Ctrl + 单击：切换 id；若取消的是主选中，主选中改为 selection 中剩余的最后加入者，空则 null。Shift + 单击：加入，主选中 = id。单击空白 / Esc：清空，主选中 null。
- **框选**：矩形状态只在 `EventTimeline` 局部（ref + 局部 state），不经 PlanningWorkspace；松开时一次 `onSelect(ids, additive)` 提交。命中按布局坐标判断（`step.elements` 的 card 元素 left/top/width/height 加平面偏移，与矩形相交），包括窗口化未渲染的卡片。按住 ⌘/Ctrl 或 Shift 开始框选时并入。框选不改时间、不平移。
- 清理：`selection` 中不在当前世界线 `wTree` 的 id 在渲染时过滤（`useMemo`），切换世界线 / 父层级时清空。

**展开按钮**：`EventCard` 头部 `⋯` 左侧新增按钮（`data-card-expand`，aria-label“展开<标题>”/“收起<标题>”，图标 ⌄/⌃），只在时间线视图（`variant="timeline"`）显示；点击立即切换展开。时间线卡片单击不再调用 `onToggle`，改调 `onSelect`。事件表卡片行为不变（单击切换 + 延迟收起保留）。`collapsedCardWidth` 加入按钮 20px + 一个 9px 间距。

**整体改时间**：
- 条件：在 `selection` 中、且 `selection.size ≥ 2` 的卡片标题上左键拖动。
- 被移动集合 `M`：对 selection 中每个事件 e，沿 `time.anchor` 链向上，若链上任一事件在 selection 中，则 e 不直接加 Δ（随锚点移动）；否则 e ∈ M。父子关系不影响时间（子事件时间独立存储），故子事件在 selection 中且自身不以 selection 内事件为锚点时也在 M 中。
- 预览：`moved` 取 M 中每个事件及“以它为锚点链传递到达的事件”的并集（去重），统一 translateX(Δ·scale)。
- 禁止：只读、有编辑中草稿、selection 中含冻结前史事件时整组禁止，提示“所选事件中有冻结前史，不能整体调整时间”。`|M| > 200` 时提示“一次最多调整 200 个事件”。
- 保存：一次 `save(M.map(put))`；失败时预览撤回、选择保留、显示领域错误（不进入编辑器）。成功后选择保留。
- 单张：selection 只含该卡或不含该卡时，沿用现有单张逻辑（并把选择设为该卡）。

**批量删除**：
- 按键：焦点在时间线根节点或其内部非输入控件、且选择非空时，Delete 与 Backspace（两平台都接受）打开批量删除确认。作为画布的局部按键处理（与现有 ↑↓←→ 相同，`EventTimeline` onKeyDown），**不加入命令目录**：worldline 作用域与 input 作用域重叠（shortcuts.ts:38），目录默认键会与 `input.deletePrevious` / `input.deleteNext` 判为冲突。焦点在搜索框、编辑器或任何输入控件时不处理，按原生行为删字符。
- `⋯` 菜单：selection ≥ 2 且本卡在其中时，在“删除”（只删本卡）之后增加“删除所选 N 个事件”。
- 对话框：`dialog` 增加 `ids?: string[]`；`delete-event` 对话框 N > 1 时标题“删除 N 个事件”，列出前 5 个标题（其余“等 N 个”），说明文字同现有。确认后一次 `save(ids.map(delete))`；领域整体校验，失败时一个都不删，显示错误，对话框关闭，选择保留。成功后清空选择。撤销一次恢复全部（同一版本）。
- 超过 200 个时提示并不打开对话框。

**批量引用**：`⋯` 菜单 selection ≥ 2 且本卡在其中时增加“引用所选 N 个事件到对话”；按 selection 内事件时间顺序，每个一行现有 `quotePlanning` 格式，一次写入输入框并聚焦。不加快捷键、不加状态行批量条（审核建议：入口只保留菜单一处）；状态行只显示“已选 N 个事件”。

### 不改

事件表（单击、展开、延迟收起、滚动）；滚轮规则（583，竖移改写 `y`）；数据模型与领域校验；小地图（只控制横向）；`fitTimelineWindow`。

## 实现中的补充（需 code review 确认）

- **原位编辑器自动露出**：车道不再滚动后，靠近车道底部的卡片打开编辑器时，“保存事件”按钮落在车道外、被底栏遮住（TL-R1 失败）。改为编辑器打开及尺寸变化时移动 `y`：能放下时整张卡片可见，比车道高时保证底部（保存 / 取消）可见。IC-11b 改为断言保存按钮在车道内、聚焦输入框不改 `y`、车道 `scrollTop` 为 0。
- **打包提速**：普通滚轮缩放每一步都全量重排（583 已知）。`settle` 原为候选位置 × 列的 O(c²) 查找，F885 上 CP-07 出现 2–4 个 > 50ms 长任务（CPU 采样中 `collides` / `settle` 占主要时间）。改为按列顶排序后单次扫描，结果与原查找相同（跳过的每个位置都与被跳过的列相撞；一旦能放在某列上方，后面的列顶更低），复杂度 O(c log c)；CP-07 回到 0 个长任务，打包单元用例（WU-15 等）全部通过。
- **⌘/Ctrl 点选**：macOS 上 Chromium 把 Ctrl + 单击转成右键菜单，不产生 click；macOS 用 ⌘、Windows 用 Ctrl 切换，Shift 两平台都可追加。IC-24（Windows）在 macOS 测试主机上改用 Shift 追加。
- 既有用例按方案更新：时间线展开改点 `[data-card-expand]`；画布平移改中键；`scrollTop` 读写改为 `data-view-y`（583 CP-01/02/04 的“滚动量”按 `−y` 相对基线计算）。事件表用例未改。
