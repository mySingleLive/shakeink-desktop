## 1 现状

- 小地图 `EventTimeline.tsx:790-826`：`<u>` 段框、`<i>` 根事件竖线（高 10 + 重要度 × 6，贴底）、`<b>` 视窗框（top/bottom 3px，只有 left/width）。`moveMini` 只设 `start`。键盘只有 ← →。
- 纵向：视口 `view.y` 是画布平移量，画布行 `[−y, −y + laneH]` 可见。排版 `step.state.packed`（`PackedLayout`）只含构建范围 `[start − 3·span, start + 4·span]` 内的家族，`families.get(rootId).y`、`box.h` 是该家族的纵向位置和高度，`packed.bottom` 是已排版的底；其下是图例行（`step.laneTop` 起）。

## 2 设计

### 2.1 纵向模型

- 内容高度 `H = max(laneH, (step.state.packed?.bottom ?? 0) + 120)`，与画布 `plane` 的高度一致（`EventTimeline.tsx:706`）。
- 小地图内部绘图区：上下各 8px 内边距，底部 14px 留给“未排版”行，纵向绘图高度 `mh = 120 − 8 − 8 − 14 = 90`px。`toMY(y) = 8 + clamp(y / H, 0, 1) × mh`，`fromMY(py) = clamp((py − 8) / mh, 0, 1) × H`。
- 视窗框纵向：`top = toMY(−view.y)`，`height = max(8, laneH / H × mh)`，上限到绘图区底。

### 2.2 标记

- 已排版的根事件（`packed.families` 中 `built` 为真）：画成 `<i data-mini-row>`，`left = toX(r.start)`，`top = toMY(f.y)`，高 `max(2, f.box.h / H × mh)`，宽 2px，颜色同现在（类型色），重要度用不透明度（1: 0.55，2: 0.8，3: 1）。
- 未排版的根事件：画在底部一行，`top = 8 + mh + 4`，高 6px，与现在一样按类型色。
- 搜索未命中的仍 `opacity 0.2`。
- 段框 `<u>` 改为 `top: 6px; bottom: 6px`（覆盖整个高度）。

### 2.3 交互

- 按下：记录 `{ dx, dy }`：按在框内时为按下点到框左上角的偏移，框外时为框的一半宽高（框中心移到指针）。拖动时 `start = toT(px − dx)`，`y = −fromMY(py − dy)`。纵向按 `[laneH − H, 0]` 夹住，即框不越出内容（内容不足一屏时 y = 0 不动）。
- 键盘：← → 不变；新增 ↑ ↓，每次 `y ± laneH / 4`，同样夹住。`aria-label` 改为“全局缩略：点击或拖动移动视窗，方向键平移”。
- 指针在底部“未排版”行按下时，纵向不变（只改时间），因为这些事件没有纵向位置；横向照常。

### 2.4 尺寸

- `worldline.module.css` `.minimap`：`height: 120px`。窄面板规则不变。
- 小地图挡住画布右下角更多：`emptyView`、居中、锚点逻辑都基于 lane，不受影响。

## 3 已知限制

- 纵向只对当前构建范围有意义；平移或缩放后重新排版，纵向位置会变，小地图随之更新（它读的是同一个 `packed`）。
- 未排版的根事件没有纵向位置，画在底部一行。

## 6 修订 1（按 `docs/596-worldline-minimap-2d-plan-review.md`）

| 审核项 | 处理 |
|---|---|
| P1-1 内容高度不含人物变化行 | `H = max(laneH, contentBottom + 40)`，`contentBottom = max(packed.bottom, step.laneTop + 最后一个变化行的 top + height)`（取 `lanePack.items` 的最大底边；无变化行时为 `packed.bottom`）。变化行画成小地图中一条浅灰横带（不画单个标记），使纵向可达 |
| P1-2 夹住 y 改变画布行为 | 不夹到固定范围，改为**相对纵向拖动**：按下不改 y；拖动时 `y = y0 − (py − py0) × H / mh`（指针下移 → 视口下移 → y 减小）。框外点击时纵向改为把框中心移到点击处：`y = −(fromMY(py) − laneH / 2)`，但当 `H ≤ laneH`（内容一屏放得下）时纵向不变。纵向结果夹在 `[min(y0, laneH − H), max(y0, 0)]`，即只限制拖动带来的越界，原本在范围外的 y（居中、复位产生的正 y）不被改动 |
| P2-1 遮挡 | 编辑器显示边距：`reveal` 的下边距从 12 改为 `12 + 小地图高 + 14`（仅当编辑卡片与小地图横向重叠时）。窄面板（< 640px 宽）小地图高仍为 120，但空视图提示（`.emptyView`，在 lane 45% 处）不受影响；复位按钮在它内部，位置不变 |
| P2-2 底行混合 | 底行只放构建范围外的根事件；被缩放分级隐藏的根事件（不在 families 中、但在构建范围内）不画标记。ZB-30 改为数 `[data-minimap] i[data-mini-root]`，每个**显示**的根事件一个，并在级别 0 与级别 6 比较“已排版 + 底行 + 隐藏”的总数等于根事件数（隐藏数由 `data-mini-hidden` 计数属性给出） |
| P2-3 ARIA | 保留 `role="slider"`、`aria-valuenow` = 时间；`aria-valuetext` 追加“，纵向 第 N / M 屏”。用例断言 ↓ 后 `aria-valuenow` 不变 |
| P2-4 键盘与 Esc | ↑↓ 每次 `y ∓ laneH / 4`，同样只限制越界；拖动中按 Esc 恢复按下前的 start 和 y（与画布平移一致），WU-66f 增加 ↑↓ |
| P3 性能 | 标记在 `useMemo`（键：`packed`、`mini`、`H`、`dimmed`）中生成，平移帧不重建；重跑 ZB-19 / ZB-20 |
| P3 框高最小值 | 框高最小 8px 只影响显示；框外点击的判断用真实框（`laneH / H × mh`） |
| docs/595 P2-2 点击窄段 | 框外点击横向改为以点击处的时间为视窗中心：`start = toT(px) − span / 2`（按下在框内仍保持偏移）。新增 MM-B8：在 mm30 夹具中点击一个 4px 宽的单事件段，该段的根事件进入视窗 |

## 7 修订 2（按 `docs/596-worldline-minimap-2d-code-review.md` 与回归结果）

| 项 | 处理 |
|---|---|
| P1-1 `sameLayout` 不在修订 1 中 | 保留并写入方案：框外点击只在新视窗仍在当前构建范围 `[lo, hi]` 内时改纵向。理由：跳到远处时新排版的纵向位置与当前小地图不对应，用户在远处点的高度没有意义；跳转后小地图显示新排版，用户再点一次即可调高度。MM-B4 改为在构建范围内点击；新增 MM-B4c：跳到很远的时间时 y 不变 |
| P2-1 编辑器边距没做 | 已做：编辑卡片与小地图横向重叠时，下边距为 `lane 底 − 小地图顶 + 14`。新增 MM-B9（关掉该改动时失败，加上后通过） |
| P2-2 MM-B5/B6/B7 纵向没测到 | 改用 `withChanges`、560px 高窗口、20 天视窗（内容高于一屏），并先断言有足够的移动空间；MM-B5 增加框左移 40 ± 1px；MM-B6 增加 ↑ 回退四分之一屏；MM-B7 断言拖动同时改了 start 和 y |
| P3-1 拖动中 H 变化 | 按下时记下 H（`h0`），拖动按它换算 |
| P3-2 底行判断 | 改为与构建范围相同：`familyEnd(r) < lo || start > hi` |
| P3-3 框在内容外 | 框高 `min(90, max(8, laneH / H × 90))`，框顶夹在绘图区内；框内判断用画出来的框 |
| P3-4 隐藏标签页 aria | `laneH = 0` 时 `aria-valuetext` 不加纵向说明 |
| P3-5 WU-66f | 增加断言 `aria-valuetext` 含“纵向 第 N / M 屏”；纵向移动量由 MM-B6 测 |

## 8 真实目标结果与修订 3

- 首次真实目标运行发现：被缩放分级隐藏的根事件不画标记，在真实作品复位视图中 371 个根事件只剩 58 个标记（docs/595 的修复被抵消）。改为：隐藏的根事件和构建范围外的根事件一样画在底行（`data-mini-row="hidden"` / `"out"`），每个根事件始终有一个标记；ZB-30 恢复为数全部标记。
- Esc：macOS 应用菜单把 Escape 绑定为“停止生成”（`ai.stop`，`desktop/shared/commands.json`），菜单加速键先于页面收到按键，所以在真实应用中拖动小地图（以及画布平移、框选）时 Esc 都到不了页面。这是现有行为，不在本次范围；Esc 恢复由浏览器夹具 MM-B7 验证。
