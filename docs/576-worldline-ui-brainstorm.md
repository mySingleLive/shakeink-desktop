# 576 · 世界线界面美化 头脑风暴记录（2026-11-15）

依据：`575-worldline-ui-research.md`。以下为与用户的问答结论，后续文档以此为准。

| # | 问题 | 用户选择 |
|---|---|---|
| 1 | 事件表竖向时间带比例尺 | **分段线性 + 断轴**：同一段内按真实时间比例，巨大间隔处断轴并标“≈ 约 N 年” |
| 2 | 事件表内卡片展开方式 | **就地展开**：原位变高，可同时展开多张 |

| 7 | 时间线视图展开方式 | **就地展开并重排**：展开后重新分行，其他卡片被推开 |

## 由结论推出的设计约束

- 严格比例下同一天最多 5 个事件（《诡秘之主》实测）会让圆点重叠：圆点允许重叠，**时间标签做避让**（与上一个标签相撞则不画，悬停/选中时显示），相距不足 4px 的圆点合并为带计数的簇点。
- 时间带与卡片列在**同一个滚动容器**中，每一段的像素高度等于该段卡片的总高度，因此展开卡片会拉长所在段，圆点与引线随之重算。
- 整棵树显示后，子事件在列表中紧跟父事件，列表顺序不再严格等于时间顺序；严格比例的圆点 + 引线照样成立（引线可能交叉，选中/悬停时高亮当前引线）。
