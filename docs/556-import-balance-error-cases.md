# 556 · 导入时模型余额不足的错误提示 测试用例

对应方案：`docs/555-import-balance-error-plan.md`。

| 编号 | 层 | 输入 | 期望 |
|---|---|---|---|
| BE-01 | 单元（`safeError`） | `Error('模型接口请求失败（HTTP 402）')` | `模型服务账户余额不足（HTTP 402），重试无法恢复。请到模型供应商充值，或在设置中更换模型后重试` |
| BE-02 | 单元（`safeError`） | `Error('Insufficient Balance')`（NI-J05 修订） | `模型服务账户余额不足，重试无法恢复。请到模型供应商充值，或在设置中更换模型后重试` |
| BE-03 | 单元（`safeError`） | `Error('IMAGE_HTTP_402')`，以及 `new ModelAuthorizationError('IMAGE_HTTP_402')` | `图像模型账户余额不足（HTTP 402），重试无法恢复。请到模型供应商充值，或在设置中更换图像模型后重试` |
| BE-04 | 单元（`safeError`，回归） | `模型接口请求失败（HTTP 400）`、`（HTTP 429）`、`（HTTP 500）` | 原样返回，不变成余额文案 |
| BE-05 | 单元（`safeError`，回归） | `IMAGE_HTTP_500`、`模型接口请求失败（HTTP 4020）`、`前缀 模型接口请求失败（HTTP 402）` | 不返回余额文案（前两者返回通用文案或原样，第三者返回通用文案） |
| BE-06 | 控制器（向导会话夹具） | 角色清单（`roster:character`）首次抛 `模型接口请求失败（HTTP 402）` | `detect-char` 为 `failed`，`stepError` 等于 BE-01 文案；「重新识别」后（模型恢复）步骤成功，`stepError` 被清除 |
| BE-07 | 控制器（向导会话夹具） | 角色导入任务（`entity`）抛 `模型接口请求失败（HTTP 402）` | 该任务 `failed`，`task.error` 等于 BE-01 文案 |
| BE-08 | 浏览器（向导组件） | 步骤失败视图，`stepError` 为 BE-01 文案 | 卡片标题「角色识别失败」，正文显示 BE-01 全文；「返回修改选择」「跳过此步骤」「重新识别」三个按钮都在 |
| BE-09 | 真实目标系统 | 开发构建 + 隔离数据根，文本模型指向返回 402 的本地桩（仅测试进程内监听，产品不开端口）；导入《诡秘之主》第一卷（小丑） | 「识别角色」失败卡显示 BE-01 文案（截图）；把模型改回可用后点「重新识别」成功 |
| BE-10 | 真实目标系统 | 已充值的 DeepSeek，同一来源 | 「识别角色」步骤成功完成（确认原问题已消除） |

BE-08 若现有浏览器用例已覆盖失败视图渲染 `stepError` 原文，则只在其中加一条文案断言。
