# 导入作品分步向导：UI/UX 设计说明

日期：2026-10-29（按 [04-ui-review.md](04-ui-review.md) 修订；同日按用户意见再修订：编码自动识别；作品名与目录移到第 3 步；识别角色、场景、物品增加自动生成图片选项）。审核稿：[design/novel-import-wizard/index.html](../../design/novel-import-wizard/index.html)。外框有主题、跳步、窗口尺寸、示例场景、"模拟识别/导入失败"开关；产品窗口为 `wizard.html`。数据均为合成示例。

## 结构

沿用现有导入对话框外壳（`.ni-dialog`：标题区、阶段条、正文、底栏），宽 920px。阶段条 6 段；窄窗口（≤700px）改为一行"阶段 N / 6 · 名称 · 第 N / 22 步"。

步骤编号与 [02-product.md](02-product.md) 一致，共 22 步：

| 步 | 名称 | 主要元素 |
| --- | --- | --- |
| 1 | 选择来源 | 选择文件 / 选择文件夹（原生） |
| 2 | 确认文件 | 文件列表、纳入复选、"编码名（自动识别）"、"编码不对？"（展开编码下拉）、核对原文、添加来源、取消；无需确认编码即可继续 |
| 3 | 作品与目录 | 作品名称（默认第一个文件名）、选择空目录；未选目录时"继续"禁用 |
| 4 | 选择内容 | "从文件导入"复选（未识别的禁用）、"根据正文补充推断"整卡复选；无模型时推断组禁用并给出"配置模型"；未选正文时按钮为"开始导入" |
| 5 | 识别卷章 | 等待动画；停止导入、上一步、收起 |
| 6 | 选择卷章 | 搜索章名、全选/全不选、全部展开/收起、手动调整卷章、计数；树：卷（展开、三态复选、"N / M 章"）→ 章（复选、查看）；"未分卷"组带"无卷标题"标签；空状态。正文与底栏之间一行发送范围（可展开说明；模型名只来自真实配置；无模型时为"仅拷贝"）；主按钮"允许分析并导入"/"开始导入" |
| 7–8 | 导入大纲结构 / 正文 | 步骤总览（默认收起为一行）+ 进度条，自动进入下一步 |
| 9 | 识别角色 | 清单上方"导入后自动生成"区：生成头像、生成立绘两个复选（默认不勾选；无图像模型时禁用并给出"配置模型"）；主按钮文字随勾选变化。每行：复选、名称、类型标签（主/配/反，点击可改）、"详情"（展开后显示别名、出场章数、来源）；搜索名称或别名、全选/全不选、合并；失败与空状态 |
| 10 | 导入角色 | 进度条与播报"已完成 N / M · K 项失败 · J 项已跳过"；实体卡格：图标（导入中做书写动画）、名称（完成后名字后打钩，带弹出动画和读屏文字）、状态；失败卡显示"重试"和"跳过"。勾选生成时每张卡下有"头像""立绘"小标签：排队/等待、转圈、完成（缩略图 + 打钩）、失败（重试/跳过）；进度摘要加"头像 a / M · 立绘 b / M"，进度条计入图像任务 |
| 11–14 | 场景、物品 | 同 9–10；场景按上级地点缩进，生成选项为外景图、内景图；物品带类型标签，生成选项为物品图标 |
| 15 | 识别世界观 | 树：世界（展开、三态复选汇总全部后代）→ 子项（类型标签 + 名称）→ 子世界嵌套；全选/全不选 |
| 16 | 导入世界观 | 按世界分组（子世界标题"父 · 子"），"其他设定"单独成组，图标不同 |
| 17–19 | 世界线、叙事线、细纲 | 步骤总览 + 进度条 |
| 20 | 导入伏笔 | 伏笔卡：名称、状态、触点数；每个触点一行：类型 + 正文/大纲/世界线/叙事线四个关联标签 |
| 21 | 校验 | 检查项逐行完成；问题项带"处理矛盾"或"重试导入某类"；列出跳过的项；有问题时"保存作品"禁用 |
| 22 | 完成 | 章节、角色、场景、物品、世界观设定、伏笔分别计数；查看导入记录、打开作品 |

附加画面：停止导入确认（继续导入；停止并保留草稿，收起后任务条可恢复；丢弃导入草稿，需再次确认）、返回修改选择（列出可返回步骤，写明将丢弃第 X–Y 步）、冲突决定（沿用现有界面）、识别失败、暂停状态。

## 交互规则

- 自动步骤完成后进入下一步；清单步骤等待作者。
- 步骤总览默认收起为"第 N / 22 步 · 名称"，点击展开 22 项：已完成打钩、当前转圈、已跳过删除线。
- 未选的类别：对应识别与导入页短暂显示"已跳过"后前进。
- 并发数 4，最多同时 4 张卡在导入中。
- 底栏（导入期间）：停止导入、返回修改选择、收起、暂停/继续导入；有失败项时加"跳过失败项并继续（N）"。
- 暂停：进度文字前加"已暂停"，中断的卡标为"已暂停"。
- 收起：关闭按钮或 Esc（不停止导入）。任务条显示"导入作品 · 第 N 步 名称 · 作品名"，清单步骤加"等待确认"，暂停加"已暂停"。
- 键盘：勾选后焦点留在原控件；对话框内 Tab 循环；Esc 先关附加画面，再收起；搜索框在组字结束（`compositionend`）后才筛选。审核稿的树不声明 `role=tree`，只用 Tab 在复选框之间移动；正式实现若使用 `role=tree`，必须同时实现方向键导航。
- 读屏：实体卡带文字状态；进度条为 `role=progressbar`；进度摘要在 `aria-live=polite` 区域，每完成一项更新。
- 减弱动态：所有转圈、书写、打钩动画和展开过渡关闭；导入中显示文字"导入中"。

## 主题与组件

- 颜色只用 `design/assets/web-tokens.css` 令牌（宣纸 `.paper`、玄墨 `.ink`）。阴影用 `--shadow-2`。遮罩沿用应用现有对话框遮罩 `#0003` + 模糊（`src/components/desktop/novel-import.css:3`），两种主题都会压暗背景；不新增令牌。
- 正式实现复用 `Dialog`、`Button`、现有 `.ni-*` 样式与 lucide 图标；新增类以 `ni-` 前缀，放入 `src/components/desktop/novel-import.css`。
