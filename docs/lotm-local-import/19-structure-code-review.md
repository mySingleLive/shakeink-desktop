## 复核发现与关闭情况

- 结构顺序：来源大纲和推断细纲均延后到世界线、叙事线之后；最终章级 artifacts 才投影到 Chapter 与 cards。
- 层级与坐标：支持实际两层/三层及“部→卷→章”，避免同级空卷、空标题章和文件内偏移/全书正文偏移混用。
- 候选完整性：按起点原子分批；多候选必须提供 `candidateId` 并忽略其余候选；章名、卷名来自真实候选或统一编号剥离/前序卷归属。
- 恢复：structure 使用独立授权、私有候选与批次指纹；同进程暂停可恢复，重开必须重新授权，正式手工确认会撤销候选与信用。
- 细纲：逐章检查唯一 `chapterIndex`、非空 canonical 文本、最终映射及陈旧/额外映射；投影先完整验证再原子替换。
- 失效：正文 patch、正式重确认及旧审核策略重建均过滤早期来源 outline 并清除旧投影与映射。
- 审计：检查全部 1,402 个细纲映射、原生 Chapter/cards、卷级摘要过滤、最终构建和关闭身份。
