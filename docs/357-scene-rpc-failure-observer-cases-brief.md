# 安全RPC观察用例

- 原post/emit的this、参数、返回值、抛出对象及监听回调顺序不变；成功响应不读/存结果资料。
- 同id正确关联、未知id/其它method/伪结构忽略；不输出请求value及秘密哨兵。
- 固定budget/unlocatable三类精确匹配；schema、有限HTTP/Prisma消息提及分类准确，未知message不回显、不猜测。
- observer读写/序列化失败不使原调用失败或吞其原错误；stop恢复原prototype、隔离目录/文件权限及队列完成。
- 私有新driver只增加observer start/stop，正常用量及场景目标、源文件、全部选择、420000ms计时/全部校验/退出门保持；旧driver字节不变。

合成控制无模型/真实数据；实际新运行仍必须另验，不将标量观察当全部场景验收通过。
