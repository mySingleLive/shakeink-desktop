## 入口与主界面

左导航和工作区各用单个“导入作品”按钮，不提供文件/文件夹模式下拉。选择框打开后，标题为“选择导入来源”，说明“可多选文件或文件夹，应用会自动识别”。

顶部为上一级、可点击面包屑及当前目录筛选。左侧列出文档、下载、桌面、盘符；窄窗口时常用位置变成可横向滚动的一行。中央列表同时显示文件夹、受支持文件及明确禁用的其他项目，文件使用已核对的本地类型 SVG，文件夹使用线性图标。

行前复选框及行内容负责勾选。文件夹双击或点击行尾箭头进入，导航不改变已选内容。文件夹行单击与双击区分：双击只进入目录，不将目录悄悄加入已选清单。当前目录本身可通过“选中当前文件夹”纳入，不必返回上一级。

底部“已选 N 个文件 · M 个文件夹”与可移除的来源清单始终位于确认按钮上方。每项显示名称与父路径，跨目录选择保留；目录与文件可混选，父目录与子文件的重叠留给后续既有核对来源阶段处理。空选择禁用“选择”。

“选择”进入合成“核对来源”结果，可返回选择或点击同一个“添加来源”界面追加。取消或关闭不创建任务；追加取消则保留原确认来源。已有确认来源时，重新点击入口恢复核对来源。

## 等待与异常

页面上方的“审核场景”仅是设计工具，不进入正式产品流程。可直接切换：

| 审核场景 | 展示行为 |
| --- | --- |
| 正常浏览 | 从文档开始，空选确认禁用；支持当前目录筛选与各类文件图标 |
| 跨目录已选 | 文件、文件夹与另一盘符资料同时保留，可移除单项 |
| 载入中 | 明确等待动画与状态，保留底部已选清单；“完成合成载入”是审核工具 |
| 无权限 | 就地说明，可返回上一级或重试，已选来源不丢失 |
| 目录消失 | 明确目录已不存在，不允许勾选该目录；可返回或重试 |
| 空目录 | 可勾选当前目录或返回上一级 |
| 确认时来源变化 | 提示移除并重新选择；确认禁用，导航不解除变化提示 |
| 添加来源 | 用同一选择框追加；取消保留此前确认的合成正文 |

不支持格式、受保护目录、无权限目录显示禁用原因。筛选无匹配显示空结果与“清空筛选”。审核稿目录切换的短等待仅表现视觉状态；生产目录读取与身份校验必须基于真实结果，不采用定时器作为完成依据。

## 主题、尺寸与键盘

沿用现有 `web-tokens.css` 的玄墨/宣纸颜色、细边框、字号与本地 NotoSansSC 字体。宽窗口为侧边常用位置加文件列表；窄窗口将常用位置横排，简化类型/大小列，正文列表与已选区分别滚动，底部取消/确认保持可达。

短窗口采用固定 `100dvh` 页面与可收缩的产品预览区，移除预览区的固定最小高度；高度不足600px时压缩审核工具、标题、目录工具与已选区，将剩余高度交给目录内部滚动。选择框的底部操作位于可收缩目录区域之外，避免由预览区最小高度将确认按钮推出窗口。

Tab 在选择框可操作元素间循环；上下方向键及 Home/End 在列表行间移动，Space 勾选，Enter 打开文件夹或勾选文件；Esc 取消。确认结果页同样支持 Esc 退出与 Tab 焦点循环。选择计数使用 live region；文件夹进入按钮、移除按钮和每行复选框有独立可读名称。

## 合成边界与后续

所有目录、盘符、文件大小与名称均为示意，页面只使用内存树；没有文件系统访问、网络请求、模型调用或生产 bridge。确认结果只展示所选来源，不将静态稿标记为真实文件解析或 Windows 验收。

待独立 UI 审核及用户审核通过后，按既定顺序进入跨平台选择器技术方案、定向用例、实现、定向测试与真实目标验证。

## 当前预览核对边界

本轮浏览器对本地文件预览给出安全策略拦截，未转用其他浏览器或启动 HTTP 服务绕过。已进行 CSS 布局结构核对及 `node --check` 语法检查；680×460、900×520 等短窗口的实际视觉与按钮可达性仍待用户人工查看或获准预览验收，不能将静态核对记为浏览器测试通过。
