## TDD 实施时的执行约束

以下是既有用例的展开方式，不新增测试范围或要求全仓回归：

- 每个表格单元里列出的多个条件须用子用例或明确断言逐一覆盖。例如NI-F03不能只测普通段落就宣告脚注/尾注/批注/页眉页脚通过；NI-W03应逐一故障注入四个发布窗口，不用一次数据库失败覆盖全部恢复分支。
- NI-L03/NI-A04应分别用可控制的在途点核对首字节前、生成中和最终用量/数据库写入期间的停止；`stop-tasks`/`close`返回时导入active应清零，不能只断言取消RPC已发送。这落实07中TR-03的既有要求。
- NI-D07/NI-U06应保留“纯正文内部矛盾”的适用选项核对，不能只验证有来源设定的标准三选和无正文的A/B取舍。
- 所有实现测试保留原用例ID及实际命令/TAP证据。未编写、未执行或受环境阻碍的分支单列，不因同组其他用例通过就标整组完成。
