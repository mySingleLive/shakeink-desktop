## 待修订问题

### PR-01 · P1 · 首次语义分类的模型发送确认位置有循环依赖

位置：产品 NI-02 首段、NI-04“发送范围”，以及整体流程。

NI-02 在“来源内容多选”之前调用模型完成语义分类，但发送确认放在其后的 NI-04，文案又限定为“所选正文和已选设定”。在首次分类时，正文/设定尚未判定、更未被用户勾选，不能据此确定授权发送范围。虽然 NI-04 写了“AI 首次处理前”，当前顺序与文案仍允许设计把确认画在首次请求之后。

建议：明确第一阶段本地提取后、语义分类前就有可见的“允许识别”动作，列出将发送的具体文件/片段、实际模型和端点；手动归类可跳过。完成来源多选后，再确认补全/复核的发送范围。两个门可复用交互，但不能由“已配置模型”或“开始导入”倒推授权首次分类。源文件新增或发送范围扩大应使相应确认失效。

### PR-02 · P2 · 无正文冲突不能沿用完整三选项

位置：产品 NI-05 无正文路径、NI-06“每项提供三种明确决策”。

无正文路径承诺仅拷贝已有资料、不生成缺失事实，但 NI-06 对所有冲突统一提供“使用推断出的设定”与“保持原设定，但修改正文”。对于只有两份人物设定冲突的导入，第二项可能引入此前明确禁止的推断，第三项根本没有正文可改；正文内部矛盾且不存在来源设定时，“坚持原设定”的主体也不明确。

建议：三项作为“正文与已有设定冲突”的标准问题；无正文时改为保留来源 A / 保留来源 B / 手动合并或补充说明，不启用正文修改，也不产生文件中不存在的事实。正文内部矛盾应标明两处原文，保留原文并解释或逐处修改。暂不决定与阻止完成规则维持一致。

## 已核对成立的关键契约

- 来源多选的“已识别默认勾选、未识别禁用”与独立补全目标分开，避免把推断当成原资料；正文取消勾选时切换到无正文路径。
- 正文初次导入保真；后续改正文必须逐处对照与二次批准，来源只读并保留最初快照。
- 有正文的逆向顺序包含大纲、人物、场景/物品、世界观、其他设定、世界线、叙事线；已有设定先拷贝，缺项依证据推断。
- “坚持原设定”不绕过已证实矛盾；未决项阻止完成，决定绑定来源版本并重算下游。
- 无明确时间时允许未知，不把倒叙或不可靠叙述误当世界事实；两条线不重新排序正文。
- 关注了独立作品目录、幂等、发布前草稿隔离、暂停/重试/恢复；不存在以文件扫描完成冒充整书分析的验收口径。
- `.doc`、`.docx` 与 PDF 文本提取的现实差异已记录，开发依赖/导出库不被误报为现有导入能力。
- 现有新书必有空 PlanningDocument，旧大纲写路径会拒绝直接编辑；产品要求保留原大纲并通过规划映射，后续技术方案需进一步给出具体承载与读写规则。
- 本任务需用户 UI 审核并禁止全量测试，文档明确覆盖旧有泛化流程要求。
