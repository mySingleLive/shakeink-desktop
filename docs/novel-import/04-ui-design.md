# 导入作品 UI/UX 设计 v4

> 2026-10-26 入口修订：用户取消文件/文件夹下拉；当前 macOS 使用统一原生选择框。下文原入口描述由 [14 方案](14-unified-source-picker.md) 覆盖，其他导入流程维持原契约。

日期：2026-10-25。产品 v1 独立审核已通过，见 [审核记录](03-product-review.md)。本稿依据 [产品文档](02-product.md)，落实用户前轮修订及本轮选项形式、默认展开要求。状态：v4 独立修订复审通过，用户已批准 v4 UI（2026-10-25），进入技术方案阶段；本轮闭环与 v1/v2/v3 历史见 [审核记录](05-ui-review.md)。不包含生产实现或正式技术方案。

## 审核入口

[交互稿](../../design/novel-import/index.html)。查看器外侧选择宣纸/玄墨、完整小说/只有正文/只有设定/无模型/读取异常，以及入口、核对来源、识别授权、内容多选、确认导入、运行、冲突、正文修改、完成。默认打开最关键的“选择内容”。所有作品、文件和计数均为合成审核资料；查看器明确标注，刷新重置，不调用应用 IPC、供应商、真实文件选择器或产品数据库。

工具区位于产品窗口外；产品内不显示版本、测试结论或调试工具。窗口只示意原品牌与入口，背景不模拟整套业务面板，正式实现复用原工作台。

## 布局与视觉

- 模态宽 920px，最大视口减 32px；最大高为视口减 32px。头/脚固定、正文独立滚动，首屏避免过密。24px 内边距、标题 21px、正文 13px、辅助 12px，圆角 12px。
- 保留原宣纸/玄墨配色与本地字体；强调使用主题主色，来源标记用原金色，成功用原成功色。禁用项有“未识别到”文字，不能仅降透明度。
- 标题下三步细线进度；步骤不作为任意跳过校验的导航。来源页保留核对说明；选择页为单栏，不出现导入计划，计划在后续确认页展示。来源复选框常规四列、700px 以下三列、420px 以下两列；补全卡片常规四列、700px 以下两列；冲突对照同步改为纵向。页脚状态说明在左，返回与主要动作在右，窄窗换行。
- 左导航入口保留既有32px规格；导入行末独立“导入方式”按钮打开文件/文件夹菜单，不把整个创建区重排成新卡片。

## 页面和动作

| 页面 | 主体与主动作 | 返回/退出 |
| --- | --- | --- |
| 入口 | “导入作品”立即进入原生文件选择位置示意；行末菜单提供“从文件夹导入” | 取消选择不创建任务 |
| 来源核对 | 文件清单使用本地真实文件类型 SVG（TXT/Markdown/Word/PDF/HTML），窄窗也保留图标；纳入/排除、顺序、全文/编码与边界核对；异常逐文件列原因 | 重新选择、取消导入 |
| 识别授权 | 在任何语义分类前显示具体文件/提取范围、实际模型/端点与发送目的；“允许识别” | 返回文件、仅本地分类；无模型时配置后返回 |
| 内容识别中 | 持续旋转环与等待点；说明正在用 AI 识别正文/大纲/角色/世界观，显示实际文件范围，无虚构百分比或倒计时 | 可收起并从原入口恢复；取消识别返回来源，保留已核对文本 |
| 内容多选 | 上方“从文件直接导入”为13类普通复选框，有来源默认勾选、无来源禁用，来源链接独立。下方“根据正文补全以下内容”为12项复选卡片，整卡手形可点击、默认全部显示，移除展开/收起操作；关闭总开关仅禁用卡片，列表仍可见。本页无导入计划 | 返回来源，下一步核对模型/目录并查看导入计划 |
| 确认导入 | 书名、独立空目录、文本/审核模型与发送范围；有AI时“允许分析并导入”，纯拷贝“开始导入” | 返回保持选择；有正文但无模型可关闭补全仅拷贝 |
| 运行 | 已完成/当前/待执行/跳过的真实步骤列表，正文保真说明；可暂停/继续、收起 | 关闭/ESC收起为“导入中”任务条；取消进入保留/丢弃确认 |
| 冲突 | 来源与正文证据对照、字段、影响范围；正文冲突三选无默认，适配无正文的来源取舍 | 暂不决定保留任务；未解阻止完成 |
| 修改正文 | 逐处diff、位置、勾选拟改项；“确认修改导入副本”二次批准 | 返回冲突；无勾选禁用确认 |
| 复核/完成 | 依赖重算提示、按来源/推断/修改/跳过分类的摘要、打开作品与查看记录 | 无正文明确未运行全书推断；原面板通过正式路由打开 |

“坚持原设定”展开解释输入，空解释不能提交；提供解释后仍需复核。选择推断先显示变更摘要再确认。修改正文先进入 diff 页，不能点击单选就改文。无正文冲突三项为来源 A、来源 B、手动合并，不出现推断/正文修改。

审核稿用窗口外“推进合成任务”显式推进运行阶段；正文与设定场景到角色步骤会停在预置冲突，也可用“查看步骤”直达冲突页。不使用计时器自动伪造完成。复制原文、不发送等状态文案是在合成状态下演示产品契约，不是产品执行证据。来源核对显示真实合成段落数量及归属；缩小范围后，其余片段须归类或明确排除，待归类时阻止继续。编码选择是交互示意，不宣称在此稿中解析真实字节；正式编码/格式转换留待后续实现。

AI 识别等待也可从窗口外步骤直接查看。点击“允许识别”先进入等待状态，由窗口外“完成合成识别”模拟回执后进入内容选择，避免把演示计时器当成真实 AI 完成依据。收起时若回执到达，保持收起并提示从任务继续，不自动弹窗打断当前操作。仅本地分类直接进入选择，不显示 AI 动画。动画采用原主题强调色，减少动态效果时静止显示状态；“内容识别中”和等待说明仍可读。文件图标来源及 MIT 许可位于 `design/novel-import/assets/file-icons/`，SVG 本地随稿加载，无运行时外链；文件名保留格式信息。

## 键盘与状态

使用原生 dialog 的焦点约束；每次进入页面聚焦标题（tabindex=-1），下一次 Tab 到第一个实际操作。页面内复选框可 Space 切换。关闭回原触发按钮；运行中收起后回任务条，无任务时回“导入作品”。工具区在模态之外、可独立切换审核视图。

书名输入、来源选择、补全目标和冲突草稿切页保留。切换工具区合成场景视为新审核会话，会明确重置；不会把上一种场景的完成状态带到另一种。减少动态效果时取消非必要过渡。

独立审核修订：后续来源核对不会重新勾选已取消的类别；用户取消原设定但保留正文补全时，计划栏明确说明。补全关闭项在运行中显示“已跳过”，完成区区分实际发现与未发现；任务主入口恢复未完成会话。冲突单选和补全卡片复选框保留焦点，模态显式循环 Tab；所有尺寸保持至少 16px 边距。纯正文内部冲突只提供解释或正文修改，不显示不存在的原设定。
