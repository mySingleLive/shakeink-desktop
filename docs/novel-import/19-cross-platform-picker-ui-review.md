## UI-01：导航和移除后须保持对话框内键盘焦点

位置：`source-picker.js` 的 `navigate`、`data-remove` 点击分支及全局 `keydown`。

按 Enter 进入已聚焦的文件夹行时，`navigate` 调用 `render`/`renderDirectory`，通过 innerHTML 移除了当前焦点行，却没有将焦点放到仍存在的目录容器或新目录内控件。移除已选按钮后同样重绘并删除焦点按钮。键盘处理函数先要求 `region.contains(event.target)`，焦点落到 body 后 Esc 不再取消，Tab 循环也不再生效，可能跳入对话框外的设计审核工具栏。

修订要求：导航、列表重绘和已选项移除后为焦点提供明确后继（例如可聚焦的稳定目录容器、当前/相邻条目或固定可操作控件），载入完成后的重绘不再次丢失焦点。保持 Esc 和 Tab 在打开的模态框内工作。复审定向操作：行聚焦→Enter 进入→载入完成→方向键/Tab/Esc；选择项移除→Tab/Esc；分别核对空目录和读取异常。

## 已核对及待主代理实际核对的细节

- 文件与目录在同一列表中，复选框/行负责勾选，行尾箭头负责进入；无预先文件/文件夹模式。底部独立保存已选集合，跨目录浏览和筛选不清空。
- 双击边界初读使用 220ms timer，可能先选中再导航。复读时作者已改为保存首击前状态，并在 dblclick 导航前恢复，不再依赖固定延时区分双击。该项静态缺口已修订，主代理仍应核对实际双击和已选目录双击。
- 当前目录 checkbox 单独纳入/移除当前目录，不影响其他选择。无权限/目录消失/受保护项与不支持文件不可勾选。错误页保留底部来源且有返回/重试。
- 空选禁用确认；确认变化场景禁用确认并要求移除重选；初次取消不建立合成任务，追加取消不改 `confirmed`。显示路径、文件图标和只读文字说明，稿件无文件系统、AI 或生产 bridge 接口。
- 样式提供双主题、宽/窄布局、列表及已选区独立滚动；请主代理特别核对 680×460、900×520 等短窗口。当前 `.app-frame` 有 550px 最小高度，可能将底部确认区推到 viewport 外，需以浏览器实际布局检查是否满足确认操作始终可达，不能只验证 390px 窄宽布局。
- UI 说明正确区分 Windows 应用内选择与 macOS 原生框，不声称完整 Linux 支持；合成盘符/文件大小/载入工具未被写作生产完成证据。

## UI-01 针对性独立复审

同日复读设计作者已保存的 `source-picker.html` 与 `source-picker.js` 修订。**UI-01 已关闭，焦点修订独立复审通过。** 未修改稿件或运行测试。

- 目录内容区现为稳定的 `tabindex="-1"` region；`focusDirectory` 在有列表时聚焦首行，在加载、空目录和错误页时聚焦该区域。
- `navigate` 重绘后显式恢复目录焦点；`renderDirectory` 在替换目录、面包屑或常用位置中当前焦点节点之前记录恢复需求，并在载入/错误/空结果及正常结果各分支恢复。异步合成载入结束不再移除焦点后将其留在 body。用户在载入中移向其他稳定控件时也不会无条件被拉回。
- 移除已选项后聚焦相邻剩余移除按钮；最后一项移除及清空均恢复到目录区域/首行。Esc/Tab 因此持续落在已打开对话框内部，可由既有键盘处理接住。
- 双击继续恢复首击前状态，再导航；选中和未选目录的双击均不会改变原选择集合。

本轮已无新的静态交互阻断。整体设计交付前仍由主代理完成已指出的短窗口和实际键盘/双击定向浏览器核对；随后可将设计稿交用户审核，用户批准仍是进入新增生产选择器技术方案的阶段门。
