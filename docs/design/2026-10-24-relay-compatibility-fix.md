# 中转模型连接与空结果修复方案

日期：2026-10-24（Asia/Shanghai）

## 目标与现象

修复已配置的自定义 OpenAI 兼容中转无法完成连接测试、AI 对话静默结束的问题。修改基于独立源码仓库，保留既有工作台、作品数据、授权边界和模型默认选择。自定义模型已明确设置上下文容量；本次不通过猜测模型容量解决网络兼容问题。

## 已复现的链路

1. 配置界面保存自定义供应商、协议、端点和模型 ID；主进程持有密钥，服务进程只拿快照及受约束的 fetch。
2. `desktop/main/model-configuration.ts` 与 `src/lib/ai/provider.ts` 直接将端点作为 API 前缀。仅填写域名根地址时，请求落在 `/models`、`/responses` 或 `/chat/completions`，未使用常见的 `/v1` API 前缀。
3. 已安装的真实 SDK（`ai` 与 `@ai-sdk/openai`）收到 HTTP 200 HTML、普通 JSON、空 SSE 或仅 `[DONE]` 时，会产生空文本和 `finishReason: other`，没有错误事件。两个独立只读审计者均通过离线 mock fetch 复现。
4. 主进程网络服务允许所有 2xx 穿透，聊天只检查存在 finish；无显式 action 的普通会话因此可能持久化为 succeeded。文本生成和上下文压缩也存在相同入口风险。
5. `ModelConfigurationDialog` 将与已揭示原密钥相等的输入转换为空字符串时，没有要求凭据作用域仍一致。修改地址后明确重输相同密钥仍可能被丢弃。

匿名实际路由探测（未使用认证材料或用户正文）：根路径下的 `/models`、`/responses` 返回 HTTP 200、`text/html`；`/v1/models`、`/v1/responses` 返回 HTTP 401、`application/json`。这证实 API 前缀问题，尚不能据此判断真实凭据、所选型号或 Responses 支持情况。

## 修复设计

### 统一 API 前缀

增加共享端点规范化函数，由连接测试与实际生成共同使用。仅自定义 OpenAI 协议、URL 路径为空或 `/` 时采用同源 `/v1` 前缀；显式 `/v1`、`/api/...`、自定义代理前缀保留，不重复追加。其他协议维持既有规则。

规范化只影响请求构造，不悄悄改写用户持久化端点，不改变凭据作用域和授权修订号。所有真实请求仍经过 `ModelGateway` 的同源、路径前缀、撤销与重定向检查。不在两个地址间自动重放付费请求。

### 拒绝伪成功响应

在共享网络/模型层完成防护，覆盖聊天、正文生成和摘要，而非只在聊天界面补提示：

- 流式文本请求的成功响应必须提供有效 `text/event-stream`，拒绝 HTML/普通 JSON；使用固定诊断码和可操作的中文说明，不回显供应商响应正文。
- 在模型输出边界检查实际终止和有效产物，拒绝空流、仅结束标记、只有推理以及异常终止；正常文本与合法纯工具调用都必须保持可用。
- 聊天终态增加业务兜底，空结果不能作为成功回执。取消、授权撤销、部分输出与工具交互保留原有恢复语义。

不在此轮顺带改写非 2xx 供应商错误分类或工具降级机制，除非该改动是已确认根因的必要修复。

### 修复明确重输凭据

只有原作用域仍匹配、用户输入等于已揭示原密钥时，才使用空字符串表示保留旧密钥。作用域变化且用户明确重输相同值时，提交显式输入；没有明确重输时仍拒绝复用旧凭据。保留手动保存和撤销边界。

### 协议选择的证据边界

源码另有 custom 同名模型继承官方能力并选择 Responses 的行为。当前尚无真实中转证据证明其不支持 Responses，不能为了一个假设静默改用 Chat Completions。先在正确 API 前缀下验证当前协议；如真实响应明确说明接口不兼容，再独立补充方案与用例，采用明确选择而非失败后付费自动切换。

## 实施顺序

1. 独立子代理审核本方案。
2. 编写独立测试用例文档并由另一子代理审核。
3. 新增回归测试，确认修复前失败；按模块实施并通过定向测试。
4. 独立代码审核，修正实际问题。
5. 执行项目完整单元/集成检查、类型检查及必要打包检查；真实 macOS 运行验证连接、对话、保存和重开。

## 验收与数据边界

- 用本地合成 HTTP/SSE 数据验证故障，不将真实密钥、用户正文或配置文件复制进源码、日志和证据。
- 真实端点验证仅通过已授权的当前供应商与原有凭据进行；只记录状态、响应类型、成功/失败和实际保存结果，屏蔽原始内容与认证材料。
- 先完成可审查的源码和安装产物；替换安装版时保留可恢复的原程序，保持用户数据目录不迁移、不覆盖。
- 未执行的平台或供应商检查明确标记未验证，不以 mock 或单次启动替代真实业务结果。

## 方案审核

独立子代理 `audit_source_generation` 已审核通过，无阻塞项。测试须明确覆盖正常非流式 JSON、纯工具调用、有部分文本的异常结束、生成/摘要共享入口及取消/授权撤销；真实认证请求另行验收。
