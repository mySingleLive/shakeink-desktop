# 585 · 世界线时间线视图：卡片时间标注随缩放提高一级精度 技术方案与测试用例

来源：用户 2026-11-17 修改要求一条，以及同日对两个问题的答复。基于 docs/584（已提交 `4a0611e`）。本文同一处给出方案与用例，按 AGENTS.md 先审核再实现。只改时间线视图卡片上方的时间标注（`.stamp`）；时间轴刻度、事件表、目录、详情不变。

## 用户要求与答复

| # | 内容 |
|---|---|
| R1 | 卡片上方的时间标注要更精确，并随时间轴缩放改变精度，始终比时间轴高一级：时间轴为年 → 卡片到月；时间轴为月 → 卡片到日；时间轴为日 → 卡片到小时（如果有的话） |
| A1 | 事件原文精度比要显示的粗时（如只写了“1349年”，月份是按位置插值出来的），照样按卡片位置细化显示，但前加“约”：`约1349年6月` |
| A2 | 小时“如果有的话”：能确定到哪个小时就显示小时；不确定就显示“上午/下午”，并加前缀“约” |

## 现状（源文件）

- `EventTimeline.tsx:577-579`：标注为 `adapter.short(start, event.time.precision)`，只看事件记录精度，与缩放无关：年精度显示 `1349年`，月精度显示 `6月`，其他显示 `6-12`。
- 时间轴标签 `adapter.label(t, view.span)` → `formatTime(d, cal, span*scale)`（`timeline.ts:54`），按窗口跨度选标签精度：
  - 有纪年的公历：跨度 ≥ 3 个平均年 → 年；≥ 90 天 → 月；否则日。
  - 固定历：跨度 > 3 年 → 年；> 3 个月 → 月；> 3 天 → 日；否则小时（`后2.5年` 等）。
  - 无纪年公历：跨度 < 48 小时 → 到分钟；否则到日。
  - `years` 历：只有年。
- 导入的事件精度只有 `day / month / year / era`（`novel-import-wizard-timeline.ts:314-346`），值在当天 0 点，或在同精度区间内插值（可能落在一天中的任意时刻）。手动新建事件精度默认 `hour`（`domain.ts:15`）。

## 方案（修订 3，回应 585 审核第 1 轮 M1–M6、第 2 轮 1–4、第 3 轮 1–2）

### 1 时间轴精度：与刻度标签同一个来源

“时间轴精度”取用户在刻度上读到的精度。新增 `axisPrecision(span, calendar): "year" | "month" | "day" | "hour"`（`timeline.ts`）：

- 有纪年公历：与 `formatTime` 同阈值，`span ≥ 3·ERA_YEAR_HOURS` → year，`≥ 2160`（90 天）→ month，否则 day；`formatTime` 改为调用它选精度（输出逐字不变）。有纪年公历刻度标签本身不到小时，但轴缩到 1 天以内时刻度间隔是小时级，这一级按 `< 48` 小时 → hour 处理，与无纪年公历一致。
- 固定历：与 `formatTime` 同阈值（严格大于）：`> 3·年` → year，`> 3·月` → month，`> 3·日` → day，否则 hour；缺年 / 月 / 日长度的那级跳过。
- 无纪年公历（M1）：刻度标签只分“到分钟 / 到日”两档，但缩到百年跨度时刻度间隔已是年级（`timelineTicks:243-254`）。轴精度改用与有纪年公历相同的跨度阈值：`≥ 3·ERA_YEAR_HOURS` → year，`≥ 2160` → month，`≥ 48` → day，否则 hour。这里轴精度与刻度标签字面不一致（标签仍是 ISO 日期，不改）；以刻度间距的尺度为准，否则百年视图下卡片会显示到“下午”，违背 R1。
- `years` 历 → year；未映射 → hour（标注本就显示“未映射”）。
- 刻度标签不变（第 2 轮 #4）：`formatTime` 只在有纪年公历分支调用 `axisPrecision`，并把 hour 映射为 day 传给 `eraLabel`（它不接受 hour，`era-calendar.ts:59`）；无纪年公历与固定历分支的标签代码不动。

`CalendarAdapter` 增加 `axisPrecision(span)`，内部用 `span * scale` 和标签日历，与 `label()` 一致（启用时间基准时也一致）。

### 2 卡片显示精度

`shown = finer(axis)`：年 → 月，月 → 日，日 → 小时，小时 → 小时。

### 3 文本

新增纯函数 `cardStamp(adapter, value, axis, time)`（`worldline-layout.ts`），`time` 取事件的 `{ kind, precision }`。按标签日历取 `civil()` 的年 / 月 / 日和当天时刻。

数值处理（M3，第 2 轮 #1，第 3 轮 #1–#2）：标注作为 adapter 方法 `stamp()` 实现（需要帧原点：纪元起点 / 公历纪元 / 固定历 0）。步骤：
1. 日：帧内小时 `h`，`日 = floor(round(h/日长·1e6)/1e6)`（与 `dayIndex`、`eraLabel` 同一规则）；当天时刻 `tod = max(0, h − 日·日长)`。
2. 分钟：`分 = floor(round(tod·60·1e3)/1e3)`，再夹到 `[0, 日长·60 − 1]`。分钟容差约 0.06 秒，小于日级容差约 0.086 秒，所以离午夜 0.06 秒以内的值已在第 1 步归到次日，不出现 `24:00`；14h − ε 显示 `14:00`，23:59.7 显示 `23:59`（与时间行的 ISO 截断一致）。
3. 年月日：用量化后的值 `帧原点 + 日·日长 + 分/60` 求 `civil()`（不改 `civil()` 本身；`short()`、`railLabel()` 不变）。这样固定历月界前 1e-7 小时的值显示为新月 1 日，不退到上月 30 日。
“在当天起点”= 分 = 0。上午 / 下午以半天（公历 12 小时，固定历 `hoursPerDay / 2`）为界。小时与分钟各补零到两位（`09:00`）。有纪年公历的年份沿用 `ERA_MAX_YEAR` 上限：超出时整段显示 `eraLabel` 的 `…年后`。

| shown | 文本 |
|---|---|
| month | `1349年6月` |
| day | `1349年6月12日` |
| hour，事件精度为 hour | `1349年6月12日 14:00`（到分钟：`14:30`。值来自用户录入的真实时刻，比“显示小时”更细但不编造） |
| hour，事件精度更粗，且值不在当天起点 | `约1349年6月12日下午`（当天时刻 < 半天为上午，否则下午；固定历按 `hoursPerDay / 2`） |
| hour，事件精度更粗，且值正好在当天起点 | `1349年6月12日`（值里没有时刻信息，不编造上午；是否加“约”按下一条） |

“约”：实际显示到的精度比事件记录精度细时加前缀（精度序：era < year < month < day < hour）。`window` 事件（起点本身不确定）一律加“约”。例：

| 轴 | 记录 | 显示 |
|---|---|---|
| 年 | 年 | `约1349年6月` |
| 年 | 日 | `1349年6月` |
| 月 | 月 | `约1349年6月12日` |
| 月 | 日 | `1349年6月12日` |
| 日 | 日（0 点） | `1349年6月12日` |
| 日 | 日（插值到 15 时） | `约1349年6月12日下午` |
| 日 | 小时 | `1349年6月12日 14:00` |
| 日 | 月（0 点） | `约1349年6月12日` |

年份缺失的日历（固定历 `monthsPerYear = null`）省略“年”段：`6月12日`。`civil()` 返回 null 的日历（`years` 历、无月份的固定历、未映射）保持现有 `short()` 输出，不加“约”。不显示纪元名（与现状一致；纪元在时期带与刻度上可见）。

### 4 渲染

- `EventTimeline` 用 `useMemo` 按 `[view.span, adapter]` 求 `axis`；平移不改变 `span`，标注不变。标注写到 `[data-timeline]` 的 `data-axis-precision`，供用例读取。
- 单事件：`cardStamp(adapter, n.start, axis, n.event.time)`。
- 父事件 `开始 → 结束`（M4，第 2 轮 #2）：起点用父事件的 `time`；终点用提供家族最晚结束值的那个节点（`famInfo` 增加 `endBy`）的 `{ kind, precision }`，该节点的 `start + duration` 也用它的精度。并列规则：与父事件并列时取父事件；只在子孙之间并列时取精度最细的（同精度取先出现的）。并列按 1e-6 天容差判断，不用 `===`。按领域校验（`domain.ts:496-513`），子孙结束不晚于父事件结束，所以终点来自子孙只发生在父事件 duration = 0、子孙在当天之内时，或父事件是 `window`（校验终点为 `windowEnd`，而 `famInfo` 取 `n.end ?? n.start`；`window` 一律加“约”，结果不受影响）。
- 性能（审核建议）：标注文本在 `useMemo([shown, axis, adapter, famInfo])` 中一次算成 `Map<id, string>`，平移帧只查表；`EventCard` 的 props 不变，WU-56c / WU-82 等渲染次数用例不受影响。
- 重叠（M5，第 2 轮 #3）：`.stamp` 加 `max-width: calc(100% - 4px)`、`overflow: hidden`、`text-overflow: ellipsis`。截断时全文仍可读：标注去掉 `pointer-events: none`，带 `title` 全文。标注在卡片之外（卡片上方），按下标注走画布空白处的路径（`EventTimeline.tsx:513` 不排除它），即框选 / 平移，与按在卡片上方空白处相同，不触发卡片单击、改时间。打包宽度不变，缩放不需要额外重排。
- `EventTree` 目录的 `short()` 不变。

### 已知取舍

- 被截断的标注全文只对鼠标悬停（`title`）可见；卡片 `aria-label` 仍为标题，读屏用户经卡片时间行读到完整时间。
- 纪元起点前 1e-7 小时的值：标注先按日容差归到新纪元 `1年1月1日`；`eraLabel` / 刻度先选纪元再取日，显示上一纪末日。标注结果更合理，二者在这一点上不同。
- 固定历负值显示 `0年12月30日` 一类的 0 年，是 `civil()` 原有行为（`railLabel` 相同），不在本次范围。
- 不显示纪元名（与现状一致）。有纪年历第四纪与第五纪可能都出现 `1349年6月`；纪元在时期带与刻度标签上可见。
- 固定历刻度写 `后342.33年`、卡片写 `343年5月`：前者是相对零点的偏移，后者是 1 基的历法日期，属现状，不在本次范围。

### 不改

时间轴刻度位置与标签文字、事件表、目录、详情对话框、编辑器；`short()` / `railLabel()` / `label()` 输出。
