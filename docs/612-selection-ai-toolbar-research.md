# 612 · 正文框选 AI 助手工具栏 调研

## 1. 需求（用户 2026-11-29）

在作品正文中框选文字后，在选区下方弹出细长的 AI 助手工具栏，对选中文字执行润色、扩写、缩写、续写、重写、总结；可先输入修改要求再选功能。处理过程在面板靠底部的迷你处理框中实时显示，完成后展示结果，作者选择「放弃」或「替换」。替换前后各记录一个历史版本，替换后可撤销。

流程：调研 → 产品设计 → HTML 设计稿（用户审核）→ 实现 → 测试。

范围按字面理解为**作品正文**，即章节内容面板（`ChapterContentPanel`）的编辑、分屏、预览三种视图。大纲、设定、世界观等其他 `MarkdownEditor` 不加工具栏（产品设计 §9 列为待确认）。

### 2.1 已有的选区浮层

正文里框选后已有两个浮层：左侧行号槽/段落左侧的「添加评论」钮，以及工具条「标注伏笔」按钮变为可用。新工具栏放在**选区末行下方、水平跟随选区**，不会盖住左侧评论钮。评论 composer 打开时不弹工具栏，工具栏打开时点「添加评论」则收起工具栏。

## 3. 同类产品的常见做法

本环境没有联网搜索工具，以下来自对 Notion AI、飞书文档 AI、WPS AI、语雀、Google Docs “Help me write” 公开界面的一般印象，未逐条核对当前版本。

1. **选中即出现浮动条**：位于选区上方或下方，第一项通常是「询问 AI / 输入指令」，后面是 2–4 个高频动作，最后是「更多」下拉。
2. **输入指令后再选动作或直接回车**：输入框下方列出动作建议，作者可只输入要求后回车，也可点某个动作。
3. **流式生成 + 可停止**：生成中显示进度和停止按钮；停止后保留已生成部分。
4. **结果确认**：完成后给「替换 / 插入下方 / 放弃 / 重试」，多数产品同时支持“在下方插入”而非一律替换；续写通常是追加到选区之后。
5. **撤销**：替换走文档本身的撤销栈（Ctrl/Cmd+Z），部分产品另有“恢复原文”。

本需求原定按钮为「放弃」「替换」，用户审核 v3 时要求在两者之间加「重试」（见 §6）；不加「插入下方」；续写与总结的替换语义需要定义（产品设计 §4.3）。

## 4. 主要技术约束

1. **三种视图坐标来源不同**：编辑视图用 Monaco 坐标；预览用 DOM Range；分屏两侧都可能有选区，以最后一次框选的那一侧为准。
2. **选区必须换算为源文偏移**：预览显示的是渲染后的文字（去掉了 Markdown 标记），替换时必须用源文 `start/end`，复用 `CommentablePreview` 已有映射。映射失败（跨越无法对应的标记）则工具栏不出现，不能猜。
3. **生成期间正文可能被改**：处理过程中作者仍可编辑别处。替换时若正文已变（选区原文对不上或版本变化），拒绝替换并提示，结果保留可复制。处理期间是否锁定正文编辑在产品设计中确定（建议不锁，替换时校验）。
4. **自动保存与服务端提交并存**：替换前要 flush 未保存输入，再以 `expectedVersion` 做 CAS 提交；回执后按 `receiveCommit` 更新编辑器，否则会与自动保存打架。
5. **撤销跨视图**：预览视图没有 Monaco 撤销栈，因此「撤销替换」必须是一次服务端提交（像恢复历史版本），不能只靠编辑器 Ctrl+Z。编辑视图里 Ctrl/Cmd+Z 是否同时可撤销替换，需在技术方案中验证（外部回执更新编辑器值后 Monaco 撤销栈的行为）。
6. **Esc**：docs/599 记录 Electron 页面里 Esc 会被渲染进程的快捷键分发器拦截（`ai.stop`），工具栏/输入框/菜单的 Esc 关闭要单独接入并在真实 Electron 中验证。
7. **默认无模型**：AGENTS.md 要求默认无模型、无平台后备。无模型时工具栏仍可出现，但功能按钮置灰并提示「请先在设置中添加模型」，不偷偷回退。
8. **隐私**：选中正文只发给作者自己配置的模型；日志与测试证据不写入真实正文。

## 5. 结论

- 前端：在 `ChapterContentPanel` 内新增选区工具栏、修改要求输入框、处理/结果框三个浮层组件；选区来源复用 Monaco 选区事件和 `CommentablePreview` 的源文映射，需要 `MarkdownEditor` 暴露“当前正文选区（源文偏移 + 视口矩形）”的回调。
- 后端：新增选区改写 SSE 路由（流式生成，返回思考与正文增量），和选区替换提交（CAS + 替换前/后两条历史版本 + 幂等回执）；撤销是带原因的反向提交。
- 输入框：复用 ChatPanel 的 composer 编辑器工具函数（`composer-editor.ts`、@ 引用、`ModelPicker`），去掉作品选择。
