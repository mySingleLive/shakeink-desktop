### 术语

代码里有两种“收起”：

- **卡片收起 / 展开**（`expanded`，时间线右侧 ⌄ 按钮，事件表单击卡片）：是否显示正文。
- **子事件折叠 / 展开**（`folded`，卡片左侧 ⌄ 圆钮，`aria-label` “折叠…的子事件”）：是否显示子事件。

本文按以下理解，设计稿审核时由用户确认：

- R1 的“收起状态”= 卡片收起（不显示正文）。
- R4 的“父事件卡片自动收起”与 R5 的“收起状态下的父事件卡片”= **子事件折叠**。层叠感表示“下面还压着子事件”，只有子事件不显示时才成立；子事件展开时父卡片是分组框的标题栏（docs/588 §1）/ 家族框的头卡，样式不变。

## 现状（源文件）

- 收起卡片：`.head` 高 32px（`worldline.module.css:115`），`.title` 单行 `white-space: nowrap`，溢出时末尾 36px 渐隐（`:122-123`，`useFade`，`EventCard.tsx:87`）。卡片总高 34px，即 `CARD_HEIGHT`（`worldline-layout.ts:23`）。
- 事件表：`tableLayout()`（`worldline-layout.ts:695`）收起卡一律 `CARD_HEIGHT`、父卡（分组标题）一律 `GROUP_HEAD_HEIGHT = 36`；圆点、引线落在 `cardHeadOffset()`（`:636`）= 卡片顶 + 17 / 18px。收起卡宽度 `fit-content`，220px 到槽宽（`.slot:not(.slotOpen) > .card`，`:206`），槽最宽 880px。
- 时间线：`buildFamilies()`（`:1230`）收起卡高 `CARD_HEIGHT`，宽 `collapsedCardWidth()`（`:1174`）按头部内容估算，夹在 150px 与 340px（根）/ 300px（子）之间；父卡宽度是整个家族的宽度。`timelineStep()`（`:1510`）每次缩放（比例变化）都整体重排。
- 滚轮缩放：`EventTimeline.tsx:294-341`，每帧合并滚轮量，`span × 1.2^n`，围绕指针时间缩放并保持指针下卡片的屏幕 y。缩放只改变时间轴比例，卡片大小不变。
- 折叠：`foldedEvents`（`PlanningWorkspace.tsx:175`）是界面状态，事件目录、事件表、时间线共用。
- 父卡样式：时间线 `.header > .card`（`:278`）只是更深的类型色渐变；事件表折叠后的分组框只剩标题栏，圆角是 `12px 12px 0 0`（`:215`），下沿是一条分隔线，看起来像被截断的框。

## 方案方向

### R1 收起卡片两行标题（事件表 + 时间线）

- `.title` 改为最多两行：`display: -webkit-box; -webkit-line-clamp: 2; white-space: normal`，行高 18px。超过两行时第二行末尾用省略号（替换现在的 36px 渐隐，`useFade` 只保留给事件目录）。
- 一行标题的卡片高度不变（34px），两行的卡片高 52px。头部其他元素（折叠钮、圆点、头像、▸ N、⌄、…）对齐**第一行**的中线，不随卡片变高而下移。
- 布局需要提前知道是一行还是两行（不读 DOM）：
  - 时间线：卡宽已由 `collapsedCardWidth()` 估算。新增 `collapsedTitleLines(input, width)`，用同一套字宽估算（CJK 13px、其他 7.4px）算标题可用宽度，得到 1 或 2 行。宽度规则不变：先变宽到上限（340 / 300px），放不下再换行。
  - 事件表：卡宽 = `min(槽宽, max(220, 内容宽))`，槽宽由面板宽度决定。`tableLayout()` 新增参数 `slotWidth`（`EventTable` 已经用 ResizeObserver 测面板宽度）。
  - 估算有误差时，像展开卡一样用 ResizeObserver 测量收起卡的实际高度（只测两行卡），下一帧修正。
- 圆点 / 引线落点：`cardHeadOffset()` 仍然是第一行中线（卡片顶 + 17px），两行卡不变，对齐模式（docs/588）不受影响。

### R2 时间线卡片随缩放变小

- 卡片缩放系数 `c` 由拥挤度 `d` 决定：
  - `d ≥ 160px`：`c = 1`（现在的尺寸，也是上限，放大时不再变大）。
  - `40 ≤ d < 160`：`c` 按对数从 1 降到最小值。
  - `d < 40`：`c` = 最小值 **0.75**（标题 10px，头部 24px，卡片 26px）。最小值待用户在设计稿里确认。
- `c` 取 0.05 的整数倍，避免每帧都重新估算宽度。
- 布局里的收起卡宽、高都乘 `c`；DOM 上 `.tcard` 设置 CSS `zoom: c`（Chromium / Electron 支持，按缩放后的尺寸参与布局，ResizeObserver 量到的也是缩放后的高度）。
- **展开的卡片和正在编辑的卡片不缩放**，保持可读可编辑。
- 时间戳（`.stamp`）和缩放后的卡片一起缩小。字号最小 10px × 0.75 ≈ 8px，太小，所以时间戳固定 10px，只限制宽度。

### R3 缩小后“一般”事件改为时间点（设计稿审核第 2 轮）

- `d < 40px` 时，重要度为“一般”（1）的事件不再画卡片，而是留下一个**时间点**：光点 + 时间日期 + 短标题，排在同一行，没有卡片和边框。“重要”和“关键”仍是卡片。真实数据中 1061 个事件里 394 个变成时间点。
- 时间点样式（设计稿审核第 3 轮）：光点就是卡片的重要度圆点（`.dot.i1 / i2 / i3`：6 / 9 / 12px，关键带外圈），放在 12px 宽的格子里居中，圆心落在事件时间上，各时间点的日期起点对齐；日期和标题都用灰色（`--muted-foreground`）；标题最多约 8.5 个字，超出时末尾 28px **渐隐**（与卡片标题的 `data-fade` 相同），不用省略号；行高 18px。父事件变成时间点时，标题后面加 `▸ N`。
- 时间点参与排版：它和卡片一样按宽度占位（高 18px），不会与卡片重叠。两个时间点之间上下间距 6px，时间点与卡片之间 16px（给卡片的日期留位置），卡片之间仍是 30px（`FAMILY_V_GAP`）。
- 父事件是“一般”、但有“重要 / 关键”的子孙事件时，父事件仍画卡片（否则整组变成一个点，子事件无处安放）。
- 总是画卡片：选中的事件、搜索当前命中、正在编辑、已展开的卡片。
- 时间点可以悬停（高亮，见 R6）、单击选中（选中后变回卡片）、双击编辑，与卡片相同。
- 只作用于时间线画布；事件目录、事件表、小地图、图例计数不变。
- 状态行提示“N 个一般事件显示为时间点”，点“显示为卡片”可临时全部画成卡片；放大到阈值以上时提示消失。

### R7 缩到最小时只有“关键”事件是卡片（设计稿审核第 3 轮）

- 第 5 级：`d < 2.5px`（暂定）时，“重要”事件也改为时间点，只有“关键”事件画卡片。父事件自动折叠（第 4 级）继续生效。
- 父事件不是“关键”、但有“关键”子孙时仍画卡片（与 R3 的规则相同，只是门槛从“重要”提到“关键”）。
- 选中、搜索命中、正在编辑、已展开的事件仍画卡片。
- 状态行提示改为“N 个一般和重要事件显示为时间点”。
- 真实数据：根事件中关键 58 个（`stats-592.json`）；复位窗口（908 年，`d ≈ 0.2px`）落在这一级。

### R6 悬停卡片时高亮它的日期（设计稿审核第 2 轮）

- 时间线视图中悬停事件卡片或时间点时：
  - 卡片：边框和外圈加强（与事件表悬停相同，`.card.hot`）。
  - 卡片上方的日期（`.stamp`）、时间点的日期：改为类型色底、白字（与事件表时间轴悬停标签相同，docs/588 §4）。
  - 顶部时间标尺上，在该事件的时间位置显示同色的日期胶囊，并从标尺向下画一条类型色虚线参考线，方便和刻度对照。
- 悬停状态只存在于时间线组件内部，不触发 PlanningWorkspace 重新渲染（沿用 IC-21b 的性能约束）。

### R4 再缩小后父事件自动折叠

- `d < 10px` 时所有父事件自动折叠子事件，画成层叠卡（R5）。
- 自动折叠只作用于时间线，不写进 `foldedEvents`，事件目录和事件表的折叠状态不受影响。
- 自动折叠时用户点父卡的折叠钮，这一个家族展开（记为例外）；放大回到阈值以上时清除例外。
- 被定位的事件（事件目录点击、搜索跳转、深链接）在自动折叠的家族里时，这个家族自动展开（与例外相同），保证能看到目标卡片。

真实数据模拟（`lod-592.json`，最密的一屏）：

| 视窗跨度 | d | 分级 | 卡片系数 | 视窗内卡片（现在 → 方案） | 画布总高（现在 → 方案） |
|---|---|---|---|---|---|
| 0.44 年 | 413px | 原样 | 1 | 16 → 16 | 954 → 954px |
| 1.8 年 | 103px | 缩小卡片 | 0.92 | 24 → 24 | 1522 → 1522px |
| 7.1 年 | 26px | + 隐藏一般 | 0.75 | 46 → 20 | 2602 → 1806px |
| 28 年 | 6.5px | + 折叠父事件 | 0.75 | 195 → 35 | 7580 → 1406px |
| 908 年（复位） | 0.2px | + 折叠父事件 | 0.75 | 1045 → 206 | 51918 → 10942px |

（模拟中卡片宽高未乘系数，实际画布还会更矮。）

### 分级的切换

- 阈值留 15% 回差：缩小时 `d < 40` 进入隐藏，放大时 `d > 46` 才恢复，避免在阈值附近来回闪。
- 每次分级切换时，以指针下的卡片为锚点保持屏幕位置（沿用现在的 `zoomAnchor`）。指针下的卡片被隐藏时，锚点改为指针时间（只保持横向位置）。
- 分级只看当前缩放，不写入作品，切换世界线、视图后按新缩放重新计算。

### R5 收起父事件的层叠卡片

适用：事件表中子事件已折叠的父卡、时间线中子事件折叠（手动或自动）的父卡。

- 四角圆角 12px（普通卡片 9px）。
- 高 40px（普通卡片 34px），标题 600 字重；背景用类型色浅底（比普通卡片深一档），加 1px 类型色描边。
- 下方露出两层“压在下面的卡”：每层向下错开 4px、左右各缩进 8px / 16px，颜色和描边逐层变淡，只露出底边 4px。下层画在上层之后（z 序更低），边线不交叉；两层都在布局预留的 8px 之内。实现用外层容器的 `::before` / `::after` 伪元素，不加 DOM 节点，不占指针事件。（设计稿审核第 1 轮：原先两层的底边超出预留高度、绘制顺序相反，线条交叉。）
- 右侧 `▸ N` 徽章保留，表示下面压着 N 个子事件。
- 布局高度：卡片 40px + 层叠 8px = 48px。`tableLayout()` 中折叠的分组改用这个高度，分组框此时与卡片重合，不再单独画框（否则框线和层叠边重复）。时间线 `buildFamilies()` 中折叠的父卡高度同样 48px（乘 R2 的系数）。
- 圆点 / 引线落点：卡片顶 + 20px（40px 的中线）。
- 两行标题（R1）时卡片高 58px，层叠部分不变。

## 备选与取舍

| 问题 | 备选 | 取舍 |
|---|---|---|
| 分级依据 | A（采用）拥挤度 `d`；B 坐标轴精度（年 / 月 / 日）；C 相对复位的缩放倍数 | B 在纪年历长跨度作品上全程是“年”，分不出层次；C 的复位窗口按数据定，不同作品含义不同；A 直接衡量“挤不挤” |
| 卡片缩放 | A（采用）CSS `zoom`，布局尺寸乘系数；B `transform: scale` | B 不改变占位，布局和点击区域对不上；A 只需布局同步乘系数 |
| 一般事件缩小后 | A（采用，审核第 2 轮）改为时间点；B 完全隐藏 | 用户要求保留时间点；B 会让读者误以为数据缺失 |
| 一般父事件有重要子孙 | A（采用）父事件仍画卡片；B 父事件变时间点 | B 的子事件没有家族框可放 |
| 两行标题 vs 加宽 | A（采用）先加宽到上限再换行；B 固定宽度直接换行 | B 会让很多短标题卡也变高，画布更高 |

## 不改

- 事件表的缩放（`k`，只改变间距，卡片大小不变）、对齐 / 等距模式。
- 展开卡片的样式和布局；事件目录。
- 图例筛选（docs/591）、搜索淡化、选择、拖动改时间、框选。

## 待审核的设计问题

1. R4 / R5 的“收起”是否指**子事件折叠**（推荐，见“术语”）。
2. 卡片最小系数 0.75 是否合适（设计稿可拖动比较 0.6 / 0.75 / 0.85）。
3. 三个阈值：“一般”改为时间点 `d < 40px`、自动折叠 `d < 10px`、只留关键卡片 `d < 2.5px`，设计稿里可以滚轮缩放查看效果。
5. 时间点的标题长度（约 8.5 个字）；悬停时标尺上的日期胶囊和竖向参考线是否需要。

（R4 模拟表中“隐藏一般”一级的卡片数按完全隐藏计算；改为时间点后卡片数相同，另有同等数量的 18px 时间点。）
4. 层叠卡样式：层数（2 层）、错开距离（4px）。
