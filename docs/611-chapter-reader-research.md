# 611 · 作品正文阅读排版 调研

## 1. 需求（用户 2026-11-28）

- 优化和美化作品正文预览的布局与 UI：章节名、标题位置偏，不醒目；字体和背景不舒服。
- 目标体验：像在专业小说网站或网文平台阅读。
- 范围：只改作品正文（章节内容面板）的预览视图。其他 Markdown 编辑器、预览、候选稿对比、冲突对比不变。
- 流程：调研 → HTML 设计稿（用户审核）→ 实现 → 测试。

## 3. 网文平台阅读页的共同做法

未联网核查，以下来自对起点读书、番茄小说、晋江、微信读书网页/客户端阅读页公开界面的一般观察，数值取常见区间，不是某平台精确值。

1. **章首居中、醒目**：章节名单独一块，居中或左对齐但大字号（约正文 1.5–1.8 倍）、加粗；上方或下方一行小字元信息（卷名、字数、更新时间）。与正文之间有明显留白。
2. **正文字号 18–20px**，行高约 1.8–2.0，段间距约 0.6–1 个字高，首行缩进 2 字。宋体/衬线或系统黑体可选，长文默认偏衬线。
3. **窄版心**：一行约 30–40 个汉字（约 680–800px），居中。宽屏两侧留出深一档的底色，中间是“书页”。
4. **护眼底色**：默认米黄/羊皮纸色，文字不是纯黑而是深棕灰；夜间模式用深灰（不是纯黑）配浅灰字，降低对比。
5. **章末标记**：分隔线或「本章完」，附字数。
6. **阅读设置**：字号、背景、行距可调（多数平台有）。

## 4. 方案方向

只动章节内容面板的预览视图（`ChapterContentPanel` → `MarkdownEditor` 预览分支）。

1. **章首块**：在预览正文第一段之前渲染章首：小字「第 N 卷 · 卷名」，大字「第 N 章 标题」（序号转中文数字；标题本身已以「第…章」开头时不重复），下方一行元信息「字数 · 状态」，再加一条短装饰线。章首随正文一起滚动，可被选中复制但不属于正文内容，不进字数、评论锚点、伏笔锚点。
2. **面板顶栏精简**：顶栏改为小号面包屑（卷名 › 章名），保留状态徽标、保存状态和「⋯」菜单，标题不再在顶栏充当主标题。
3. **版心与字体**：版心约 720–760px 居中；正文 18px、行高约 1.95、段距约 0.7em、缩进 2em；两个主题正文都用衬线字体（Noto Serif SC → 宋体）。
4. **背景**：宣纸主题正文区为浅米色“书页”，宽面板时两侧是深一档的纸色并给书页加极轻阴影；玄墨主题书页用暖深灰（非纯黑），正文浅灰暖色，降低对比。窄面板（< 约 820px）时书页铺满，不留两侧。
5. **章末**：正文末尾加「· 本章完 ·」分隔标记。
6. **阅读设置（可选，待审核决定）**：字号（小/中/大）、背景（主题默认/护眼绿/羊皮纸等）。若采纳，按 AGENTS.md「其他设置即时持久化」。

实现方式：`MarkdownEditor` 增加可选 `previewHeader`/`previewFooter` 与 `previewVariant="reader"` 之类的入参，只由 `ChapterContentPanel` 传入；其余调用方不传，渲染保持原样。分屏模式、评论、伏笔、选区菜单、文本右键菜单都需要继续工作。

## 5. 待用户审核的问题

- 章首样式：居中（起点/番茄式）还是左对齐（微信读书式）。设计稿默认居中，可切换。
- 是否加入阅读设置（字号/背景）。设计稿可演示。
- 顶栏是否保留章节名面包屑。
