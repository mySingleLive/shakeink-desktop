# 554 · 异常作品统一导航节点 总结

需求：用户 2026-11-10。产物顺序：调研 `550` → 设计稿 `design/faulted-work-node/index.html` v3（用户批准）→ 方案 `551` 及审核 → 用例 `552` 及审核 → TDD 实现及 code review `553` → 全量与真实目标系统验证 → 本文。

## 结果

- 异常作品与正常作品使用同一导航行（作品视图）/分组标题（其他视图）；图标为作品目录+感叹号合成图标；标题错误类柔和红、警告类柔和黄（两主题实测色值与批准稿一致）。
- 六类异常：目录不可用、作品锁未释放、作品正在别处使用、目录已变化、数据无法读取、作品暂不可用。分类只认结构化标记，错误类型与文案不变。
- 单击/Enter/Space/`…`/右键打开同一菜单；作品锁类有“修复作品锁”，全部有“重新加载作品”和“删除”。
- 任何作品都可删除：异常作品经 `DELETE /api/works/{id}` 从列表移除并删除关联对话，不读写目录文件；任务运行中返回 409，结束后可删；连接无法关闭时仍完成删除。
- 正常作品菜单内容不变（重命名、删除），新增右键入口。
