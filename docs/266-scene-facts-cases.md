日期：2026-10-31，依据265方案和独立审核。

- **SF-01 内层恢复与净化**：首轮facts增加不合法键，第二轮模型只有在实际纠错prompt含固定完整字段说明时才改正；两次内恢复。未知键和值用合成敏感哨兵，feedback与公开错误不回显。说明不超过250 UTF-16 code units，实际第二轮feedback保留schema2全部13个字段名。
- **SF-02 有界外层**：controller→runImportAi→generateImportAiJson前两次非法、第二请求instruction含同一完整说明后第三次恢复，精确2请求/3生成；持续非法精确2请求/4生成后failed，无伪成功artifact或skip。不本地删键通过。
- **SF-03 接受集合**：全部13字段均合法时，text、四原生字段、知识归属、合法关联、父级及引用逐值不变；缺省控制元数据仍只从可信目录补全。未知键（含undefined）、非法facts形状/值、显式坏PLACE/父级和无效证据继续拒绝，不覆盖原请求。普通scene及角色/其它阶段不使用新集合指导。
- **SF-04 回归与真实**：既有场景/SL/SH、授权/证据、旧协议和发布定向用例，类型检查、构建及独立code review。失败目标只读复测仅证明该目标；新session原件全文、全章、全部本轮候选全选导入，最终零失败跳过丢弃警告、ID/父级/正文一致，正常保存退出并重开逐字段/逐章比较后才能声明完整成功。保留R14不通过，不跑全仓测试。
