## 逐事实正确性方法

每条生成材料先拆解为可分别核验的陈述。复合句中的主体、行为、对象、关系方向、因果、数量、否定、条件、先后与认知归属分别检查；不能用一句可命中的引文为整段内容背书。`facts`中JSON字符串需按实际结构展开，别名/关系数组、世界设定树和叙事refs全部逐项核对，不能只检查外层字符串。

审核证据至少包括该章完整语境；出现代词、转述、回忆、虚构身份或后期反转时，扩展到相邻段/相关前后章，必要时关联多个卷的证据。短引文命中只用于定位。以下情况均不能算有据：把某人说的话变成客观事实、把推测变成结论、把发生先后变成因果、把早期属性当作全书永久属性、把最终揭示的真相写成早期角色已知。

同一事实可能由多个材料或一个跨章材料承载，允许有据的合并和摘要，不强制一章一个artifact。但逐章必要内容必须能定位到准确表达；“某artifact引用了这个unit”或一个全书总述并不自动覆盖该章。原文自身不确定时，输出应保留对应不确定性，不能为了消冲突强行统一。

逐陈述台账还须指向实际原生字段或可见规划表达。若正确内容只在导入记录materials/facts中、业务对象却丢失重要信息，记为原生表达丢失，不能以“原文文件还在”当作该业务已正确导入。
