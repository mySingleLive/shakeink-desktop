## 结论

**方案与 PREP01–03 审核通过，允许在候选B最终输入独审通过后准备正式输入。** 从已下载完整主线按有据范围提取正文，补充独立官方目录的卷标题并转换为明确标识的UTF-8文件，属于本任务合理的测试数据准备，不要求另行授权；前提是正文、章节顺序和全部叙事内容保持原样，且下载原件与实际导入文件的身份始终分开记录。

这能用于验收“来自网络下载的《诡秘之主》第一部完整主线正文与八类业务导入”，不降低九项正确性标准。但它不能证明“网络原件直接导入时自动恢复缺失卷标题”，也不能被表述为“未经准备的原字节全文件导入”或“全部已发表番外完整”。候选A的FAIL、候选B原件缺第八卷标题的事实及其直接导入边界继续保留。

## 执行时必须落实

1. **先完成10的最终输入核验。** 22/22已知乱码位置在B正常只说明已知A缺陷改善，不能独立证明B所有1394章完整或全文无异常。B的原字节hash、严格解码、八卷/1394章顺序和边界、官方目录对照及剩余质量异常须由最终独审明确。若该门槛仍FAIL/BLOCKED，准备文件不能把它转成PASS。
2. **区分字节与字符表示。** PREP01的相等应定义为：B按记录编码严格解码、禁止换行转换后的八段原文，重新编码为UTF-8；与派生输入按登记位置移除8个完整新增标题块后的UTF-8字节逐一相等。它不是与B的GB18030/其他原字节直接相等。范围需标明UTF-16半开位置，并另记UTF-8字节hash；存在补充平面字符时不得把Python字符位置直接冒作UTF-16位置。
3. **新增块边界也需冻结。** 每个新增块记录卷序、确切标题文本、CRLF、派生起止位置和来源目录条目；除这8个块外不得新增分隔空白或变换原文行尾。先去除8个完整新增块再验证主线拼接，而非用字符串全局替换，避免误删正文内恰好同名的文字。原有7处卷标题已由独审范围排除，不能重复进入首章。
