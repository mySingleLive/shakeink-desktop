## 断言强度与状态

事前独立语义清单的少量关键项是最低门槛，不能代替全文正确性审核。所有生成事实需核对原文，遗漏需按完整章序检查；“引文命中”“字段可解析”“类别非空”“模型自评”“completed”分别只是局部证据。无法完成全量语义核验时相应项目为待验，不写 PASS。

结果只使用 PASS、FAIL、BLOCKED、NOT RUN，分别记录机械测试与真实全书测试。来源门槛未通过时可以只读研究及定位已发现缺陷，但不能把组件测试或损坏来源试跑替代正式全流程验收。只运行本用例及实际修复所必需的定向回归；不运行全仓测试。
