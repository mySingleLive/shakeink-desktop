# 581 · 世界线界面改版 测试用例

依据：`577-worldline-ui-product-design.md`、`580-worldline-ui-plan.md`。编号前缀 WU。数据均为合成内容，真实作品只在 §5 的隔离根中使用。

## 1. 数据与导入（单元 / 集成）

| 编号 | 场景 | 输入 | 期望 |
|---|---|---|---|
| WU-01 | 默认值 | 旧作品 `events` 中没有 `category`、`importance` | 解析成功；值为“其他”和 1；保存后再读出不变 |
| WU-02 | 校验 | `category:'未知'`、`importance:0 / 4 / 1.5 / '2'` | 解析失败，报错指向该字段；其它事件不受影响 |
| WU-03 | 分叉冻结 | 源事件只改 `category` 或 `importance` | `forkChanged` 计数不变（不提示“源事实已有变化”） |
| WU-04 | AI 工具 | put 一个带 `category:'揭示', importance:3` 的事件；再 put 不带这两个字段的同 id 事件 | 第一次写入两个值；第二次保留原值（与其它字段的合并规则一致） |
| WU-05 | 导入契约 | 世界线提示文本 | 含 `category` 的 7 个取值和 `importance` 1–3 的说明 |
| WU-06 | 导入整理 | 回复中 `category:'打斗'`、`importance:5`、`importance:'2'` | 非法值丢弃（发布后为默认值），不报错，不丢事件 |
| WU-07 | 发布 | 会话中事件 `category:'冲突', importance:2`，正文超长被拆成 3 片 | 3 片都是“冲突 / 2” |

## 2. 布局纯函数（单元，`worldline-layout.ts`）

| 编号 | 函数 | 场景 | 期望 |
|---|---|---|---|
| WU-10 | eventTree | 3 层父子，同层乱序，含 2 个待定位、1 个父事件缺失的子事件 | 同层按开始时间排序；待定位单独列出；缺父事件的子事件提到根层 |
| WU-11 | familyEnd | 父事件 10–20，孙事件结束于 25 | 25 |
| WU-12 | railSegments | 885 个事件按《诡秘之主》分布合成（3 年内 851 个、远古 34 个） | 远古与近期之间断开；1348–1350 年不被拆开；每段至少 1 个事件 |
| WU-13 | railPositions | 同一天 5 个事件 | 圆点 y 严格按比例；4px 内合并为 1 个簇点，计数 5；簇点标签只画 1 次 |
| WU-14 | railPositions | 标签间距 < 18px | 后一个标签不画；该事件被选中时仍画 |
| WU-15 | packFamilies | 30 个家族首次排布 | 任意两个家族外框不相交；按开始时间先到先得 |
| WU-16 | packFamilies | 平移：窗口起点变化 20 次，比例不变 | 已构建家族的 y 全部不变（只调用一次全量排布） |
| WU-17 | packFamilies | 展开家族 A 的一张卡片（高度 +160） | A 的 y 不变；只有与 A 横向相交且在 A 下方的家族下移；其余家族 y 不变；无相交 |
| WU-18 | packFamilies | 收起 WU-17 的卡片 | 所有家族回到原位 |
| WU-19 | packFamilies | 只构建窗口附近家族；起点相隔 20 万年 | 所有坐标的绝对值 < 1e7px；平移跨越构建范围后新家族加入，原家族 y 不变 |
| WU-20 | minimapModel | 2 段（远古 34、近期 851），宽 420 | 两段宽度按事件数分配，段间距 14；`toT(toX(t))` 误差 < 1 小时；点击最左端得到最早事件附近 |
| WU-21 | matchEvent | 关键字“码头 冲突”；角色名“艾伦”；大小写英文 | 多关键字全部出现才命中；匹配标题、内容、角色名、类型名、时间说明；英文不区分大小写 |

## 3. 浏览器测试（真实 `WorldlinePanel`，内存接口数据）

数据：合成 60 个事件（与设计稿 v9 相同的结构：4 个父事件、2 个孙事件层级、2 个待定位、4 个时期、相隔 20 万年的远古事件、6 名角色）。另有一组 885 个事件的合成数据，用于性能和重叠测试。

### 3.1 卡片与工具栏

| 编号 | 场景 | 期望 |
|---|---|---|
| WU-30 | 默认状态 | 两个视图中所有卡片收起；收起卡片高 34px，只显示圆点、标题、头像、子事件数；不渲染事实正文 |
| WU-31 | 单击展开 | 显示类型标签、时间、正文、人物、角色变化、菜单；`aria-expanded=true`；再次单击收起 |
| WU-32 | 双击 | 进入现有原位编辑器；编辑中卡片保持展开；保存后回到收起或展开前的状态 |
| WU-33 | 颜色与大小 | 7 种类型各有不同的色条和圆点颜色；重要度 1/2/3 的圆点直径依次增大；图例计数与数据一致 |
| WU-34 | 类型筛选 | 单击图例隐藏一类：卡片、目录、圆点、引线同步变淡；双击只看这一类 |
| WU-35 | 文字溢出 | 超长标题：计算样式没有 `text-overflow: ellipsis`；溢出的标题有渐变遮罩；未溢出的没有 |
| WU-36 | 头像 | 收起卡片最多显示 4 个（事件表）/ 3 个（时间线），超出显示 `+N`；有头像和无头像的收起卡片高度相同 |
| WU-37 | 全部展开 / 收起 | 按钮文字随状态切换；全部展开后无卡片重叠 |
| WU-38 | 工具栏样式 | 标题 18px / 500；按钮高 28px；“＋ 事件”底色等于 `--primary`；玄墨和宣纸两种主题都检查 |
| WU-39 | 窄窗口 | 1440、1280、1160、1024、900px 宽：工具栏单行，没有控件超出 |
| WU-40 | 更多菜单 | 包含世界线设置、＋ 世界线、＋ 时期、时期列表、跨世界连接、单位与对应、时间基准、显示时期、显示角色变化；每项打开现有的对话框或切换现有状态 |

|---|---|---|

### 3.3 时间线

| 编号 | 场景 | 期望 |
|---|---|---|
| WU-50 | 父事件标题栏 | 宽度 ≥ 家族时间范围；子卡片都在框体内（越界 0）；标题栏上方显示起止时间 |
| WU-51 | 拖动画布 | 先滚动 160px，再拖动 24 帧：屏幕内卡片垂直移动 0；重叠 0；纵向滚动位置不变；屏幕内卡片不消失 |
| WU-52 | 展开 | 被展开卡片位置不变；其他家族的卡片不移动；重叠 0 |

| WU-54 | 缩放 | Ctrl + 滚轮缩小 3 档：重叠 0 |
| WU-55 | 拖动改时间 | 拖动卡片标题改时间：预览期间其他家族不移动；松开后保存，时间改变 |
| WU-56 | 小地图 | 点击最左端跳到远古事件；拖动方框平移；聚焦后按 → 前移 1/4 视窗 |
| WU-57 | 角色变化泳道 | “显示角色变化”开启时泳道存在并位于事件区域下方，关闭时消失 |

## 4. 性能（885 个事件，浏览器测试 + 真实应用）

| 编号 | 指标 | 目标 |
|---|---|---|
| WU-80 | 事件表首次渲染 | < 500ms |
