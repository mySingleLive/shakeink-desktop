# 581 · 世界线界面改版 测试用例（修订 2，对应方案修订 7）

依据：`577-worldline-ui-product-design.md`、`580-worldline-ui-plan.md`（修订 7）。修订 2 回应 `581-worldline-ui-cases-review.md` 中的 F1–F8 和建议。编号前缀为 WU，按编号排序。数据均为合成内容；真实作品只在 §6 的隔离根中使用。

## 0. 约定

- **层级**：U 表示单元测试（`node --test`，纯函数或 store）；B 表示浏览器测试（真实 `WorldlinePanel` 加内存接口数据，沿用 `planning-card-menu.test.ts` 的打包方式）；E 表示真实 Electron（隔离根，LotmVerification.app）。每条用例只在标注的层级上判定。
- **渲染计数**（F2）：需要统计渲染次数的 B 层用例，打包时把 `react-dom` 换成 `react-dom/profiling`，并把 `NODE_ENV` 设为 `"development"`（只用于这组用例的打包）。测试通过 `<Profiler onRender>` 计数。每组计数用例先做一次**正向对照**：先触发一次会让组件渲染的操作（例如选中卡片），断言计数 > 0，证明计数器有效，再执行被测操作。E 层不统计渲染次数，只测每帧耗时和长任务。
- **固定数据**：F60 是与设计稿 v9 结构相同的 60 个事件：4 个父事件、2 层孙事件、2 个待定位事件、4 个时期、相隔约 20 万年的远古事件、6 名角色（其中 3 名有头像）。F885 是 885 个事件，分布与《诡秘之主》第一卷相同（3 年内 851 个，远古 34 个），其中 40 个父子家族、120 个事件有叙事引用。
- **只能由固定数据覆盖的用例**：《诡秘之主》第一卷导入后没有父子层级，没有待定位事件，参与角色也都为空。凡依赖这三类数据的用例都标注“固定数据”，台账中写明“真实数据未覆盖，仅固定数据浏览器测试”。
- **基线**（F7）：标注“基线”的用例，先在改版前的提交 `195b4c0` 上实现并跑通，再在改版后的代码上跑一次。断言内容不能放宽，只允许按 §7 列出的选择器对照表修改选择器。
