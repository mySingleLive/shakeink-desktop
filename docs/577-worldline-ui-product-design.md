# 577 · 世界线界面美化 产品设计

依据：`575-worldline-ui-research.md`（现状）、`576-worldline-ui-brainstorm.md`（用户决策）。设计稿：`design/worldline-redesign/index.html`。

## 范围

- 改：世界线面板（`WorldlinePanel`）的工具栏、事件卡片、[时间线] 视图、[事件表] 视图。
- 不改：数据模型、导入流程、叙事线/大纲投影面板、事件编辑器字段。展开/折叠状态只是界面状态，不写入作品，也不产生版本。
- 基础：`fix/worldline-chronology`（纪元历法）提交后在其上实现。

## 1. 工具栏（更简洁）

一行，左右两组：

- 左：`[主世界线 ▾]`　`[时间线 | 事件表]`（分段切换）　`[＋ 事件]`
- 右：`待定位 N`、`延续事件 N`（为 0 时淡化），`[⋯ 更多]`：世界线设置、＋ 世界线、＋ 时期、时期列表、跨世界连接、单位与对应、时间基准、显示时期 ✓、显示角色变化 ✓。
- 面包屑只在时间线视图且进入子层时出现。范围文字（“第五纪1349年5月 — …”）和“当前层 · N 件事件”合成一行淡色状态文字。

## 2. 事件卡片：收起 / 展开

| 状态 | 内容 | 尺寸 |
|---|---|---|
| 收起（默认） | 时间点圆点 + 标题（单行，超长省略，悬停显示全文）。有子事件时尾部显示 `▸ N` | 高 34px；时间线视图中宽度 ≤ 240px |
| 展开 | 现有卡片的全部内容：时间行、事实正文、人物、角色变化、子事件入口、引用、`⋯` 菜单 | 高度自适应；时间线视图宽 320px |

- 单击卡片（非按钮处）切换展开/收起。双击仍为原位编辑；编辑中的卡片总是展开。
- 可同时展开多张。工具栏 `⋯ 更多` 内提供“全部收起”。
- 选中态：卡片边框与对应时间点高亮。
- 收起态不渲染事实正文（`MarkdownPreview`），降低 885 个事件时的渲染成本。

## 3. 事件表视图（三栏）

```
┌ 树形菜单 240px ─┬ 时间带 160px ─┬ 卡片列（自适应）────────┐
│ ▾ 父事件      3 │ 新历1024 ┬    │ ● 父事件标题            │
│     子事件 A    │  3月5日 ●─────│   ● 子事件 A            │
│     子事件 B    │        ●╲     │   ● 子事件 B            │
│   事件 C        │         ╲─────│ ● 事件 C（展开）        │
│ 待定位        2 │  ≈ 约 47 万年 │   正文…                │
└─────────────────┴───────────────┴─────────────────────────┘
```

### 3.1 树形菜单

- 按子事件层级：根事件 → 子事件，同层按开始时间排序；待定位事件放在末尾的“待定位”分组。
- 行：折叠箭头、小圆点、标题（省略）、短时间（如 `3-05`）。有子事件时显示子事件数。
- 点击行：卡片列平滑滚动，使该卡片位于视口上方 1/3 处；卡片与时间点闪烁高亮 1.2 秒并成为选中项。不自动展开。
- 折叠树节点 = 卡片列中隐藏其子事件（时间带上的点同步隐藏，父事件的点显示 `+N`）。
- 滚动卡片列时，树中对应当前视口顶部的事件行高亮，并自动滚入树的可见区。
- 键盘：`role="tree"`，↑↓ 移动，←→ 折叠/展开，Enter 定位。

### 3.2 竖向时间带（分段线性 + 断轴，严格比例 + 引线）

- 一条竖线贯穿整列，与卡片列同一滚动容器，同步滚动。
- **分段**：按开始时间排序所有可见已定位事件；相邻两事件间隔同时大于 30 天和“相邻间隔中位数 × 20”时，在此断开。每段的像素高度 = 该段卡片的总高度（展开卡片会拉长所在段）。
- **断轴**：段与段之间画 44px 高的断轴记号（双斜线），标“≈ 约 N 年 / N 个月 / N 天”。
- **段内严格比例**：`y = 段顶 + (t − 段起点) / (段终点 − 段起点) × 段高`；只有一个事件的段，点在段中间。
- **时间点**：直径 10px 圆点。时点 = 实心；有持续时间 = 实心点 + 沿竖线到结束时刻的半透明胶囊；时间窗口（不确定起点）= 空心点 + 虚线胶囊；开放结束 = 胶囊渐隐。
- **时间标签**：在竖线左侧，右对齐，按事件精度显示（日精度 `1349年12月1日`，月精度 `1349年12月`，时精度带时分）。与上一个已画标签间距 < 18px 时省略；省略的标签在悬停/选中该事件时显示。
- **刻度**：段内在年 / 月分界处画短刻度和淡色刻度文字，间距 < 48px 的刻度不画。
- **引线**：每个点到其卡片标题行左缘画一条三次贝塞尔曲线（1px，淡色）。悬停或选中卡片时该引线加粗并使用主色。
- 相距 < 4px 的多个点合并为一个带计数的簇点（悬停列出事件）。

### 3.3 卡片列

- 按树的顺序排列（深度缩进 16px/层）。收起卡片紧密排列（间距 6px）。
- 断轴位置在卡片列中对应插入同高的空白，使段与卡片对齐。

## 4. 时间线视图（横向画布）

- 保留：刻度尺、时期色带、拖空白平移、Ctrl+滚轮缩放、方向键、全貌、拖标题/时间条改时间、双击编辑、子事件层级（面包屑）、角色变化泳道、待定位/延续弹层。
- 卡片默认收起为 34px 高的胶囊，左端圆点位于开始时刻；持续事件在胶囊下方画时间条。分行打包按收起高度计算，一屏可容纳数十个事件。
- 点击胶囊 → 就地展开为 320px 宽完整卡片，重新分行打包，其他卡片被推开（布局变化做 180ms 过渡）。
- 每个胶囊上方的圆点旁标出简短时间（与刻度粒度一致），画不下时省略。

### 5.1 事件着色（用户 2026-11-15 追加）

要求：为了美观，不同事件卡片用不同颜色。着色依据从类型、参与角色、重要程度中评估。

| 依据 | 数据现状 | 优点 | 问题 |
|---|---|---|---|
| 参与角色 | `eventSchema.people` 已有。但《诡秘之主》导入后 885 个事件的 `people` **全部为空**（`wl-era1/worldline-readback.json`） | 不需要新字段 | 一个事件常有多名角色，只能取第一个人的颜色，含义含糊；角色多于 6–8 人时颜色无法区分；《诡秘之主》现在会全部显示为灰色 |
| 事件类型 | 没有此字段 | 7 种类型（冲突、谋划、揭示、关系、成长、变故、其他）颜色可区分，一眼看出情节节奏；可按类型筛选 | 需要新增字段，导入时由模型判断，旧事件默认“其他” |
| 重要程度 | 没有此字段 | 关键事件醒目，适合在 885 个事件中快速找主干 | 只有 3 档，主要靠深浅区分，用作唯一颜色依据时画面单调 |

**推荐 D：颜色表示类型，大小与粗细表示重要度。** 两个维度互不冲突：色相显示“是什么事”，圆点大小、标题粗细和 ★ 显示“有多重要”。图例可点击，只看某一类，其余淡化。按角色着色不作为默认，因为一事多人含义不清；角色更适合做筛选。

数据影响（选定后进入技术方案）：
- `eventSchema` 新增 `category`（7 选 1，默认 `其他`）和 `importance`（1 一般 / 2 重要 / 3 关键，默认 1）。两者都有默认值，旧作品不需要迁移。
- 事件编辑器增加这两项。导入时由第 17 步的事件提取一并输出，已导入的作品可由用户手动修改，或重新导入。
- 着色依据作为界面偏好（不着色 / 类型 / 角色 / 重要度 / 类型 + 重要度），持久化在本机设置，不写入作品。

## 6. 性能与可访问性

- 时间带布局（分段、y 坐标、标签避让、簇点）放入 `src/lib/planning/timeline.ts` 的纯函数，单元测试覆盖。
- 目标（《诡秘之主》885 事件，真实应用）：事件表首次渲染 < 500ms；展开一张卡片到重新布局完成 < 100ms；滚动无 > 50ms 长任务。若不达标再加虚拟列表。
- 卡片 `aria-expanded`；树 `role="tree"/"treeitem"`；时间点有 `aria-label`（标题 + 时间）。

## 8. 用户决策（2026-11-15）与 v2 设计稿

- 视觉风格：**A 沉稳暗色 + 微光**，并在此基础上继续美化。B、C 两种方案已从设计稿删除。
- 着色依据：**按类型**。重要度不参与显示，所以 `importance` 字段不新增，只新增 `category`（冲突、谋划、揭示、关系、成长、变故、其他，默认“其他”）。界面上不再提供“着色依据”选项。

v2 设计稿（`design/worldline-redesign/index.html`，文件为 `base.css`、`views.css`、`app.js`、`data.js`）在 A 风格基础上增加：
- 卡片：左侧有类型色条（带微光），背景从类型色渐变到卡片底色；悬停时卡片右移 2px；展开时显示类型标签、时间、持续方式，正文行距 1.75，人物用头像胶囊，角色变化显示为“前 → 后”。子事件数在收起时显示为 `▸ N`。
- 类型图例：显示每类计数；单击隐藏或显示这一类，双击只看这一类；隐藏的类型在卡片、树、圆点、引线上同步淡化。
- 树形菜单：顶部有标题搜索框，根事件按年份分隔（只用于显示，层级仍按父子事件），当前项左侧有类型色条。
- 时间带：竖线两端渐隐、带柔光；年份徽章放在线上，月份用短刻度；断轴记号旁注明“相隔 约 N 年”；圆点为类型色加外圈光晕，选中时放大并显示彩色时间标签；同一位置的多个事件合并为簇点，簇点外圈按类型色分段显示；滚动时顶部固定显示当前年份。年精度事件不再重复显示年份标签。
- 时间线视图：月份刻度高亮，时期带用渐变色；每张卡片上方有类型色的时间点，并标出日期；持续事件画渐隐的时间条；右下角有全局缩略条（每个事件一条类型色竖线，方框表示当前视窗）。
- 亮色主题：所有类型色另有一套亮色版本。

## 9. 用户修改（2026-11-15 第二轮）与 v3 设计稿

| 要求 | 设计 |
|---|---|
| 颜色按类型，**圆点大小按重要程度** | 恢复 `importance` 字段（1 一般 / 2 重要 / 3 关键，默认 1）。颜色只表示类型；时间带圆点直径 9 / 13 / 17px，“关键”再加一圈缓慢扩散的光环；卡片标题前的小圆点、树形菜单圆点、时间线视图的时间点按同样三档缩放。图例右侧显示大小说明 |
| 体现父事件与子事件的层次 | **事件表**：父事件和它的子事件放在同一个分组框里，框体用父事件类型色淡染；子事件缩进，左侧有父事件色的竖向连接线和横向分支；嵌套的子父事件再嵌一层分组框。父事件标题行显示持续条、子事件数（含全部后代）、折叠按钮 ▾。时间带上父事件的真实跨度画成较宽的半透明胶囊，子事件圆点落在其中；子事件的引线为虚线。**时间线视图**：父事件下方画一个横跨其真实时间的“括号”和淡色底板，子事件在括号内分行排列，整个家族不与其他事件混排；子事件卡片用虚线边框，收起时父卡片显示 `▸ N` |
| 顶层工具栏选择时期并定位 | 工具栏新增“时期”下拉：列出全部时期（色块、起止时间、事件数，被包含的时期缩进），首项为“全部时期（全貌）”。选择后：时间线视图把视窗缩放到该时期，并让时期色带闪烁；事件表滚动到该时期的第一个事件，时间带旁对应的时期竖条闪烁；顶部提示“已定位到时期「…」· N 件事件”。事件表时间带右侧新增时期竖条（竖排文字） |
| 工具栏展开/收起所有卡片 | 工具栏新增一个切换按钮：有未展开卡片时显示“全部展开”，全部展开后变为“全部收起”。“⋯ 更多”里原有的“全部收起”删除 |
| 事件表 Ctrl + 滚轮缩放时间轴间距 | 事件表支持 Ctrl + 滚轮，缩放范围 100%–400%。放大时按相邻根事件的时间间隔增加卡片之间的空白，因此时间带上的间距按比例拉开；指针下的卡片缩放前后位置不变。工具栏缩放控件 `− 100% ＋ 复位` 在两个视图通用（时间线视图显示视窗天数） |

数据影响：`eventSchema` 新增 `category` 和 `importance`，都有默认值，旧作品不需要迁移；导入时由模型判断这两项。

## 10. 用户修改（2026-11-15 第三轮）与 v4 设计稿

| 要求 | 设计 |
|---|---|
| 收起状态也显示参与角色头像，尽量不增加面积 | 头像放在收起卡片标题行的右侧，直径 18px（时间线视图 16px），相互重叠 5px，叠在原有 32px 行高内。事件表最多显示 3 个，时间线视图最多 2 个，超出显示 `+N`；悬停显示全部角色名。头像为角色头像图片，没有图片时用姓名首字和由名字确定的颜色。展开后不显示头像叠层，改由正文下方的人物胶囊显示姓名。实测：有头像和没有头像的收起卡片高度都是 34px |
| 小地图可点击、拖拽移动视口 | 小地图宽 300px，覆盖全部已定位的根事件。分段规则与事件表时间带相同，每段宽度按事件数分配，段之间留 10px 断轴记号，所以相隔 20 万年的远古事件也能点到。每个事件一条竖线（类型色，高度按重要度）。交互：点击方框外 → 以点击位置为中心跳转；按住方框拖动 → 平移视窗，缩放比例不变；点击后不松开可以接着拖；聚焦后按 ← → 每次平移视窗宽度的 1/4。小地图浮在画布上方，有半透明底和阴影，不遮挡卡片的点击（画布底部留出 56px） |

实测（Playwright，设计稿）：点击最左端跳到“旧纪119年12月29日—旧纪120年3月9日”；点击 55% 处跳到“新历1348年11月3日—1349年1月13日”；拖动方框 48px 后为“1348年12月8日—1349年2月18日”；按 → 后前移 18 天。

## 13. 用户修改（2026-11-15 第六轮）与 v7 设计稿

| 要求 | 设计 |
|---|---|
| 时间线视图和事件表共用一套左侧树形事件导航菜单 | 页面结构改为“左侧事件目录 + 右侧视图区”，事件目录只有一份，切换视图时保持不变（折叠状态、滚动位置、选中项都保留）。目录顶部显示“事件目录”；在时间线视图中，右侧还显示“视窗内 N 件”。工具栏最左侧新增按钮，可以隐藏或显示事件目录，两个视图通用 |
| 在时间线视图中点击菜单项，快速定位到对应的事件卡片 | 统一使用一个定位操作，按当前视图执行：**事件表**中，卡片滚动到视口上方 1/3 处；**时间线**中，把视窗平移到事件开始时刻位于宽度 30% 处，缩放保持不变；如果父事件的家族比视窗的 60% 还宽，就缩小到能完整显示，然后纵向滚动到该卡片所在的行。两个视图中卡片都闪烁高亮，并成为选中项。目标事件的父事件被折叠时自动展开。点击“待定位”事件时，因为它不在时间轴上，会自动切换到事件表，并提示“待定位事件只在事件表中显示，已切换到事件表”。搜索结果跳转、时间带圆点、待定位按钮都使用同一个定位操作 |
| （联动）目录与时间线同步 | 时间线视窗内的事件在目录中标记为“视窗内”（圆点外圈发光，行尾有类型色细条），视窗中最早的事件标为当前行。平移、缩放或拖动小地图后，目录自动滚动到当前行；鼠标停在目录上时不自动滚动，避免打断操作 |
| （修复）时间线卡片重叠 | 原来按“行”分组：前一个家族很高时，后面的卡片会叠到它的框里。改为二维排布：每个家族先单独排好并量出外框，再放到不与已放置家族相交的最高位置，按开始时间依次放置。时间线底部留出 96px，最后一行也能滚动到小地图上方 |

实测（Playwright，设计稿）：时间线视图中目录可见（60 行，视窗内 26 件）。点击“雨夜列车在河谷脱轨”（父事件）、“一名乘客下落不明”（孙事件，原先被折叠）、“星图指向南方群岛”（最后一行）、“大洪水淹没低地王国”（相隔约 20 万年的远古事件），四张卡片都完整出现在视口内，并成为选中项。拖动小地图后目录当前行跟随移动。点击待定位事件会切换到事件表并显示提示。目录可以隐藏（宽度 0）。家族之间的重叠：默认视图、定位后、全部展开、缩小到 236 天，四种情况都是 0 处。页面没有报错。
