# 577 · 世界线界面美化 产品设计

依据：`575-worldline-ui-research.md`（现状）、`576-worldline-ui-brainstorm.md`（用户决策）。设计稿：`design/worldline-redesign/index.html`。

## 范围

- 改：世界线面板（`WorldlinePanel`）的工具栏、事件卡片、[时间线] 视图、[事件表] 视图。
- 不改：数据模型、导入流程、叙事线/大纲投影面板、事件编辑器字段。展开/折叠状态只是界面状态，不写入作品，也不产生版本。
- 基础：`fix/worldline-chronology`（纪元历法）提交后在其上实现。

## 1. 工具栏（更简洁）

一行，左右两组：

- 左：`[主世界线 ▾]`　`[时间线 | 事件表]`（分段切换）　`[＋ 事件]`
- 右：`待定位 N`、`延续事件 N`（为 0 时淡化），`[⋯ 更多]`：世界线设置、＋ 世界线、＋ 时期、时期列表、跨世界连接、单位与对应、时间基准、显示时期 ✓、显示角色变化 ✓。
- 面包屑只在时间线视图且进入子层时出现。范围文字（“第五纪1349年5月 — …”）和“当前层 · N 件事件”合成一行淡色状态文字。

## 2. 事件卡片：收起 / 展开

| 状态 | 内容 | 尺寸 |
|---|---|---|
| 收起（默认） | 时间点圆点 + 标题（单行，超长省略，悬停显示全文）。有子事件时尾部显示 `▸ N` | 高 34px；时间线视图中宽度 ≤ 240px |
| 展开 | 现有卡片的全部内容：时间行、事实正文、人物、角色变化、子事件入口、引用、`⋯` 菜单 | 高度自适应；时间线视图宽 320px |

- 单击卡片（非按钮处）切换展开/收起。双击仍为原位编辑；编辑中的卡片总是展开。
- 可同时展开多张。工具栏 `⋯ 更多` 内提供“全部收起”。
- 选中态：卡片边框与对应时间点高亮。
- 收起态不渲染事实正文（`MarkdownPreview`），降低 885 个事件时的渲染成本。

## 3. 事件表视图（三栏）

```
┌ 树形菜单 240px ─┬ 时间带 160px ─┬ 卡片列（自适应）────────┐
│ ▾ 父事件      3 │ 新历1024 ┬    │ ● 父事件标题            │
│     子事件 A    │  3月5日 ●─────│   ● 子事件 A            │
│     子事件 B    │        ●╲     │   ● 子事件 B            │
│   事件 C        │         ╲─────│ ● 事件 C（展开）        │
│ 待定位        2 │  ≈ 约 47 万年 │   正文…                │
└─────────────────┴───────────────┴─────────────────────────┘
```

### 3.1 树形菜单

- 按子事件层级：根事件 → 子事件，同层按开始时间排序；待定位事件放在末尾的“待定位”分组。
- 行：折叠箭头、小圆点、标题（省略）、短时间（如 `3-05`）。有子事件时显示子事件数。
- 点击行：卡片列平滑滚动，使该卡片位于视口上方 1/3 处；卡片与时间点闪烁高亮 1.2 秒并成为选中项。不自动展开。
- 折叠树节点 = 卡片列中隐藏其子事件（时间带上的点同步隐藏，父事件的点显示 `+N`）。
- 滚动卡片列时，树中对应当前视口顶部的事件行高亮，并自动滚入树的可见区。
- 键盘：`role="tree"`，↑↓ 移动，←→ 折叠/展开，Enter 定位。

### 3.2 竖向时间带（分段线性 + 断轴，严格比例 + 引线）

- 一条竖线贯穿整列，与卡片列同一滚动容器，同步滚动。
- **分段**：按开始时间排序所有可见已定位事件；相邻两事件间隔同时大于 30 天和“相邻间隔中位数 × 20”时，在此断开。每段的像素高度 = 该段卡片的总高度（展开卡片会拉长所在段）。
- **断轴**：段与段之间画 44px 高的断轴记号（双斜线），标“≈ 约 N 年 / N 个月 / N 天”。
- **段内严格比例**：`y = 段顶 + (t − 段起点) / (段终点 − 段起点) × 段高`；只有一个事件的段，点在段中间。
- **时间点**：直径 10px 圆点。时点 = 实心；有持续时间 = 实心点 + 沿竖线到结束时刻的半透明胶囊；时间窗口（不确定起点）= 空心点 + 虚线胶囊；开放结束 = 胶囊渐隐。
- **时间标签**：在竖线左侧，右对齐，按事件精度显示（日精度 `1349年12月1日`，月精度 `1349年12月`，时精度带时分）。与上一个已画标签间距 < 18px 时省略；省略的标签在悬停/选中该事件时显示。
- **刻度**：段内在年 / 月分界处画短刻度和淡色刻度文字，间距 < 48px 的刻度不画。
- **引线**：每个点到其卡片标题行左缘画一条三次贝塞尔曲线（1px，淡色）。悬停或选中卡片时该引线加粗并使用主色。
- 相距 < 4px 的多个点合并为一个带计数的簇点（悬停列出事件）。

### 3.3 卡片列

- 按树的顺序排列（深度缩进 16px/层）。收起卡片紧密排列（间距 6px）。
- 断轴位置在卡片列中对应插入同高的空白，使段与卡片对齐。

## 4. 时间线视图（横向画布）

- 保留：刻度尺、时期色带、拖空白平移、Ctrl+滚轮缩放、方向键、全貌、拖标题/时间条改时间、双击编辑、子事件层级（面包屑）、角色变化泳道、待定位/延续弹层。
- 卡片默认收起为 34px 高的胶囊，左端圆点位于开始时刻；持续事件在胶囊下方画时间条。分行打包按收起高度计算，一屏可容纳数十个事件。
- 点击胶囊 → 就地展开为 320px 宽完整卡片，重新分行打包，其他卡片被推开（布局变化做 180ms 过渡）。
- 每个胶囊上方的圆点旁标出简短时间（与刻度粒度一致），画不下时省略。

## 5. 视觉风格（待用户在设计稿中选定）

| 方案 | 要点 |
|---|---|
| A 沉稳暗色 + 微光 | 现有主题 token（主色 `#e07a5f`），去粗边框，细线刻度，时间点外发光，半透明时期色带 |
| B 霓虹科技 | 深蓝黑底，青/品红霓虹，渐变时间带，较强发光与扫描线 |
| C 古典史册 | 墨色/羊皮纸色，金铜细线，衬线标题，罗盘式时间点 |

亮色主题下三种方案都提供对应配色。选定一种后只实现该方案。

### 5.1 事件着色（用户 2026-11-15 追加）

要求：为了美观，不同事件卡片用不同颜色。着色依据从类型、参与角色、重要程度中评估。

| 依据 | 数据现状 | 优点 | 问题 |
|---|---|---|---|
| 参与角色 | `eventSchema.people` 已有。但《诡秘之主》导入后 885 个事件的 `people` **全部为空**（`wl-era1/worldline-readback.json`） | 不需要新字段 | 一个事件常有多名角色，只能取第一个人的颜色，含义含糊；角色多于 6–8 人时颜色无法区分；《诡秘之主》现在会全部显示为灰色 |
| 事件类型 | 没有此字段 | 7 种类型（冲突、谋划、揭示、关系、成长、变故、其他）颜色可区分，一眼看出情节节奏；可按类型筛选 | 需要新增字段，导入时由模型判断，旧事件默认“其他” |
| 重要程度 | 没有此字段 | 关键事件醒目，适合在 885 个事件中快速找主干 | 只有 3 档，主要靠深浅区分，用作唯一颜色依据时画面单调 |

**推荐 D：颜色表示类型，大小与粗细表示重要度。** 两个维度互不冲突：色相显示“是什么事”，圆点大小、标题粗细和 ★ 显示“有多重要”。图例可点击，只看某一类，其余淡化。按角色着色不作为默认，因为一事多人含义不清；角色更适合做筛选。

数据影响（选定后进入技术方案）：
- `eventSchema` 新增 `category`（7 选 1，默认 `其他`）和 `importance`（1 一般 / 2 重要 / 3 关键，默认 1）。两者都有默认值，旧作品不需要迁移。
- 事件编辑器增加这两项。导入时由第 17 步的事件提取一并输出，已导入的作品可由用户手动修改，或重新导入。
- 着色依据作为界面偏好（不着色 / 类型 / 角色 / 重要度 / 类型 + 重要度），持久化在本机设置，不写入作品。

## 6. 性能与可访问性

- 时间带布局（分段、y 坐标、标签避让、簇点）放入 `src/lib/planning/timeline.ts` 的纯函数，单元测试覆盖。
- 目标（《诡秘之主》885 事件，真实应用）：事件表首次渲染 < 500ms；展开一张卡片到重新布局完成 < 100ms；滚动无 > 50ms 长任务。若不达标再加虚拟列表。
- 卡片 `aria-expanded`；树 `role="tree"/"treeitem"`；时间点有 `aria-label`（标题 + 时间）。
