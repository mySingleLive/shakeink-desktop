# 612 · 正文框选 AI 助手工具栏 产品设计

调研见 `docs/612-selection-ai-toolbar-research.md`，HTML 设计稿见 `design/selection-ai-toolbar/index.html`。

## 1. 范围

- 作品正文（章节内容面板）的**编辑、分屏、预览**三种视图。评审视图没有正文，不出现工具栏。
- 六种 AI 修改功能：润色、扩写、缩写、续写、重写、总结。
- 三个浮层依次出现：选区工具栏 → （可选）修改要求输入框 → 处理框（处理中 / 已停止 / 完成）。
- 替换写入两条历史版本，替换后可撤销。
- 不含：大纲、设定、世界观等其他编辑器；候选稿、历史版本、冲突对比中的只读正文；「插入到下方」等需求外按钮。

## 2. 选区工具栏

### 2.1 出现条件

全部满足时，松开鼠标（或用 Shift+方向键选取后停顿 300 ms）即弹出：

1. 选区在正文内，去掉空白后至少 1 个字。预览视图的选区能换算到源文位置（换算方式与「添加评论」相同）；换算失败不弹出。
2. 正文不处于整章 AI 生成中（顶栏「正在生成候选稿」时正文只读）。
3. 当前没有未结束的处理框（同一章一次只处理一段）。
4. 评论输入框、伏笔引用选择框、阅读设置弹框都未打开。

选区跨越多段、含 Markdown 标记都可以。超过 10000 字时工具栏照常出现，功能按钮置灰，悬停提示「选中文字超过 1 万字，请缩小范围」。

### 2.2 位置与外观

- 细长条：高 34 px，圆角 8 px，浮于正文之上，带轻阴影，宣纸/玄墨两套配色。
- 默认位于**选区最后一行下方 8 px**，水平以选区末行的中点为中心；超出正文区域左右边缘时贴边内收 8 px。下方空间不足（距底部 < 50 px 或会被处理框遮住）时翻到选区首行上方。
- 正文滚动时随选区移动；选区滚出可视区时隐藏，滚回时恢复。窗口或面板宽度变化时重新定位。

### 2.3 内容（从左到右）

| 项 | 形态 | 动作 |
|---|---|---|
| 添加评论 | 主色图标按钮（对话气泡 + 加号，与现有「添加评论」浮钮同一图标），悬停提示「添加评论」，右侧一条分隔线 | 工具栏消失，打开现有评论输入框，对选中文字评论（见 §2.6） |
| 输入修改要求 | 带笔形图标的浅色“伪输入框”，宽约 140 px，文字「输入修改要求…」 | 工具栏消失，原位置弹出修改要求输入框（§3），焦点进入输入框 |
| 润色 | 图标 + 文字按钮 | 直接开始润色（§4） |
| 扩写 | 图标 + 文字按钮 | 直接开始扩写 |
| 续写 | 图标 + 文字按钮 | 直接开始续写 |
| ⋯ | 图标按钮，悬停提示「更多 AI 修改」 | 向下展开菜单：润色、扩写、缩写、续写、重写、总结（每项图标 + 名称 + 一行说明），点击即开始 |

各功能说明（菜单第二行文字，也是给模型的默认要求）：

| 功能 | 说明 | 默认要求 |
|---|---|---|
| 润色 | 优化措辞与节奏，不改情节 | 保留原意、情节、人称和信息量，改善用词、句式和节奏 |
| 扩写 | 补充细节，篇幅约增加一半 | 不改变情节走向，补充动作、神态、环境与心理描写，约为原文 1.5 倍 |
| 缩写 | 精简冗余，保留关键情节 | 保留关键情节与对白要点，删去冗余，约为原文一半 |
| 续写 | 接着选中内容往下写 | 承接选中文字的最后一句往下写，风格一致，约 300–600 字 |
| 重写 | 换一种写法重新表达 | 保留情节要点，换一种叙述方式与句式重写 |
| 总结 | 概括为一段简述 | 用一段话概括选中内容的情节要点 |

模型上下文：选中文字、其前后各约 1500 字、本章标题、作品名、本章细纲（若有）。只发送给作者配置的模型。

### 2.4 关闭

点击正文别处使选区折叠、按 Esc、切换视图、开始评论、右键（交给原生右键菜单）、选中文字被编辑时，工具栏关闭。点击工具栏本身不会折叠选区。

### 2.5 不可用状态

- **没有可用模型**：工具栏照常出现；「输入修改要求」可以打开、可以输入；所有功能按钮置灰，悬停提示「请先在 设置 → 模型 中添加模型」。不回退到任何平台模型。
- **正文只读**（整章生成中）：不弹出（§2.1）。

### 2.6 添加评论

直接沿用已实现的选区评论，不新做评论框和评论流程：

- 点击后效果与现有「添加评论」浮钮相同：选中文字按评论锚点高亮，评论输入框（`CommentComposer`）出现在选区最后一段之后（编辑视图为 Monaco 行内区域，预览为段落之后），焦点进入输入框。
- 输入框的按钮、草稿保留、Cmd/Ctrl+Enter 发表、收起/丢弃、Esc 关闭、提交后锚点与评论卡片显示，全部保持现有行为。
- 评论框打开期间拖选新文字不弹 AI 工具栏（与现有「评论框打开期间不响应新选区」一致）；关闭后恢复。
- 只读正文（整章生成中）不出现工具栏，评论入口同样不可用；评审视图没有工具栏。
- 原有左侧「添加评论」浮钮是否保留，见 §9。

## 3. 修改要求输入框

外观与 AI 对话输入框一致但更小：宽 560 px，正文区不够宽时为正文宽度 − 32 px；输入区最少约 2 行、最多约 6 行后滚动。位置与工具栏相同（选区下方，空间不足翻到上方）。打开时选区上下都放不下输入框，正文先自动滚动一次，让输入框完整显示在选区下方；选区本身过高时不滚动，输入框贴底显示。

```
┌───────────────────────────────────────────┐
│ ❝ 他推开门，看见……   │  已选 326 字        │  ← 选中文字摘要：引号图标 + 浅底圆角条（单行截断）
│ 写下修改要求，@ 引用角色/场景…             │  ← 可编辑区，1–6 行自动增高
│ [+]                        [模型 ▾]        │  ← 底栏
├───────────────────────────────────────────┤
│ ✦ 润色   优化措辞与节奏，不改情节          │
│ ⤢ 扩写   补充细节，篇幅约增加一半          │
│ ⤡ 缩写   精简冗余，保留关键情节            │  ← 功能列表（输入框下方）
│ → 续写   接着选中内容往下写                │
│ ↻ 重写   换一种写法重新表达                │
│ ≡ 总结   概括为一段简述                    │
└───────────────────────────────────────────┘
```

- **保留的对话输入框功能**：@ 提及（角色/场景/大纲等实体 chip，与对话相同的弹窗与键盘操作）；「+」菜单中的「插入角色·场景·大纲」；模型与思考强度选择（`ModelPicker` 同款，选择只对本次修改生效，默认取对话当前模型）；粘贴、剪切、撤销、输入法组合输入。
- **去掉**：作品选择（固定为当前作品）、标准/计划模式、发送按钮、「插入 # 会话」「插入 / 命令」、图片/附件（对话中也仅为「即将支持」）。
- **功能列表**：点击任一项，按「功能默认要求 + 作者输入的要求」执行该功能。输入为空时等同于在工具栏直接点该功能。
- **键盘**（与对话输入框一致）：
  - 输入框内 ↑/↓/←/→ 移动光标，不切换功能。@ 弹窗打开时 ↑/↓ 在候选实体间移动。
  - 功能列表中有一项高亮（主色浅底 + 主色图标和名称），表示当前选择的功能。输入框打开时默认选择「润色」；换了选区再打开时恢复为润色。
  - **⌘↑ / ⌘↓（macOS）、Alt+↑ / Alt+↓（Windows）**：在输入框中直接切换当前选择的功能，高亮上移或下移一项，首尾循环。焦点和光标留在输入框，位置不变，可以接着打字。这两个组合在本输入框内覆盖系统原有的「光标移到开头/结尾」行为；另一平台的组合键（macOS 的 Alt+↑↓、Windows 的 Win/Meta+↑↓）不切换功能。输入法组合输入中不响应。@ 弹窗打开时也不响应，避免和候选选择混淆。
  - Enter 执行当前选择的功能；Shift+Enter 换行；输入法组合输入中的 Enter 不执行。
  - 鼠标点任一功能直接执行该功能；悬停只显示浅灰底，不改变选择。
  - Tab 把焦点移到当前选择的那一项；在列表中 ↑/↓ 移动，高亮随之移动（即改变选择），Enter/空格执行；在第一项按 ↑ 或 Shift+Tab 回到输入框末尾，选择保持。
  - Esc：@ 弹窗打开时先关弹窗，否则关闭输入框并恢复正文选区。
  - 输入框底部提示随当前选择和平台变化，例如 macOS「Enter 执行润色 · ⌘↑↓ 选择功能 · Shift+Enter 换行 · Esc 关闭」，Windows「Enter 执行润色 · Alt+↑↓ 选择功能 · …」。Tab 进入功能列表仍可用，但不再写在提示里。
  - 这组快捷键按 AGENTS.md 的快捷键约定接入设置中的快捷键列表（可录制、多绑定、冲突转移），默认值即上述按键；具体在技术方案中确定。
- **关闭**：Esc、点击输入框外的正文。已输入的要求在同一选区内保留（关闭后从工具栏再打开仍在）；选区变化后清空。

## 4. 处理框

### 4.1 位置

固定在正文区**底部居中**，距底边 16 px，宽 min(640 px, 正文区宽 − 32 px)，不随正文滚动。出现时工具栏/输入框消失，选区原文在正文中保持浅色底纹高亮（编辑视图用 Monaco 装饰，预览用同色 mark），方便对照。右下角评分指示器上移让位。

### 4.2 处理中

```
┌────────────────────────────────────────────────┐
│ ▸ 已思考 6 秒                                  │  ← 推理模型才有，默认折叠
│ 他推开门的那一刻，屋里的灯忽然暗了下去……       │  ← AI 输出实时追加，自动滚到底
│ ▍                                              │
├────────────────────────────────────────────────┤
│ ◌ 润色中 · 已生成 128 字              [■ 停止]  │  ← 状态栏
└────────────────────────────────────────────────┘
```

- 上部高 160 px，只显示 AI 的消息：思考（推理模型，折叠为「思考中…/已思考 N 秒」，与对话一致）和正在生成的文字。作者输入的要求不在这里显示（状态栏悬停可查看）。用户向上滚动时停止自动滚到底，回到底部后恢复。
- 状态栏：旋转图标 +「{功能}中」+「已生成 N 字」；右侧图标按钮「停止」。

### 4.3 已停止

点「停止」后中止生成，保留已生成部分。状态栏变为「已停止 · 已生成 N 字」，右侧两个图标按钮：

- **继续**（▶）：从已生成内容末尾接着生成，状态回到「{功能}中」。
- **放弃**（✕）：丢弃结果，处理框消失。

已停止的不完整结果不提供替换，避免把半截文字写进正文。

### 4.4 失败

网络、模型错误或输出为空：状态栏显示红色「{功能}失败：原因」，按钮为「继续」（重新请求，已有部分作为前文）和「放弃」。

## 5. 结果框（文本展示框）

生成正常结束后，处理框原地向上长高（约 160 → 260 px，200 ms 过渡），内容变为最终可替换文本：

- 正文用与正文预览相同的段落排版（首行缩进），可选中复制，不可编辑。
- 思考记录收起为一行「已思考 N 秒」，可展开。
- 状态栏：「{功能}完成 · 原文 326 字 → 412 字」；右侧三个按钮，从左到右 **[放弃]**（描边）、**[重试]**（描边）、**[替换]**（主色）。

各功能替换写入的内容：

| 功能 | 结果框显示 | 「替换」写入选区位置 |
|---|---|---|
| 润色 / 扩写 / 缩写 / 重写 / 总结 | 生成文本 | 生成文本替换选中原文 |
| 续写 | 选中原文（灰色）+ 续写部分（正常色） | 选中原文 + 续写部分，即续写接在选区之后，原文不丢 |

- **放弃**：丢弃结果，所有浮层消失，正文和选区高亮恢复原状。
- **重试**：相当于重新抽卡。用同一功能、同一修改要求、同一选区和模型重新生成；当前结果直接丢弃（不保留多稿供挑选）。处理框缩回「处理中」状态，状态栏显示「{功能}中 · 第 N 次」，完成后显示「{功能}完成 · 第 N 次 · …」。重试不改正文、不产生历史版本，可以重复多次。若选中原文在此期间已改动，重试按改动前的原文生成，替换时仍按 §6.1 校验并拒绝。
- **替换**：见 §6。成功后浮层消失，新文字在正文中闪烁一次高亮并滚动到可见。

## 6. 替换、历史版本与撤销

### 6.1 替换

1. 先保存正文中未保存的输入。
2. 校验：选区原文仍然逐字在原位置，正文版本没有被其他写入改变。不满足时不替换，状态栏提示「正文在处理期间已改动，无法替换。结果已保留，可复制后手动修改」，按钮变为「复制结果」「放弃」。
3. 一次提交完成：**先**把替换前的正文记为历史版本，原因「AI 润色前」（按功能名变化）；**再**写入替换后的正文，记为历史版本，原因「AI 润色」。即使替换前的正文刚被自动保存过，也会新增这条「AI 润色前」版本。
4. 生成内容为空、与原文完全相同或生成未正常结束时，不出现替换按钮（§4.3、§4.4）。

### 6.2 撤销

替换完成后，处理框位置显示一条撤销提示条：「已替换为润色结果　[撤销]　[✕]」，持续 10 秒，或在作者再次编辑正文、开始新的 AI 任务时消失。

- 点「撤销」：恢复替换前的正文，作为一次新提交，原因「撤销 AI 润色」，在版本历史中可见。提示「已撤销」。
- 编辑或分屏视图中，替换后紧接着按 Cmd/Ctrl+Z（光标在正文内、此后没有其他编辑），效果与「撤销」相同。
- 替换后正文已被继续编辑：撤销条消失，「撤销」不再提供，避免覆盖新输入；作者可在「⋯ → 版本历史」中查看「AI 润色前」版本并恢复。

### 6.3 版本历史显示

| 时机 | 原因文字 |
|---|---|
| 替换前 | AI 润色前 / AI 扩写前 / … |
| 替换后 | AI 润色 / AI 扩写 / … |
| 撤销后 | 撤销 AI 润色 / … |

显示方式（沿用现有「⋯ → 版本历史」页面，不另开窗口）：

- 列表每行为「修订 N · 原因 · 字数 · 时间」。现有列表不显示原因，本功能为每行加上原因：AI 修改产生的三类版本用主色浅底标签并带 ✦ 图标，其他原因（正文更新、AI 生成正文、恢复正文版本 N）用灰色小字。
- 刚由本次替换/撤销产生的行，打开列表时以浅绿底淡出提示一次。
- 点任一版本进入详情：标题「历史正文 · 修订 N」，下方是原因标签、字数、时间、只读；展开「与当前稿比较」看段落差异；右上角「恢复为当前稿」（恢复也保存为新修订）。
- 「AI 润色前」详情的正文就是替换前的全文，「AI 润色」是替换后的全文。

## 7. 其他交互与边界

- **处理期间继续写作**：正文不锁定，作者可编辑其他位置；编辑若改动了选区原文，状态栏立即提示「选中原文已改动，完成后无法直接替换」。
- **切换标签页**：处理继续，回到该章时浮层状态保持。**关闭标签页或切换到其他章节**：中止生成并丢弃结果。
- **切换视图**（编辑/分屏/预览）：工具栏和输入框关闭；处理框、结果框保持，选区高亮在新视图中重新绘制。
- **与整章 AI 生成互斥**：处理框存在时「⋯」菜单中的「AI 生成正文 / 重新生成正文」置灰，提示「请先完成或放弃当前 AI 修改」。
- **窄面板**（正文宽 < 480 px）：工具栏「输入修改要求」收为笔形图标按钮；润色/扩写/续写保持文字；输入框和处理框宽度为正文宽 − 32 px。
- **键盘可达**：工具栏出现后按 Tab 可聚焦进入；工具栏、菜单、功能列表支持方向键和 Enter；处理框按钮可 Tab 聚焦。Esc 按 §2.4/§3 关闭（在 Electron 中需绕开快捷键分发器对 Esc 的拦截，docs/599）。
- **用量**：每次功能执行计入现有用量记录，动作名区分功能（如 `selection.polish`）。

## 8. 验收要点

| 编号 | 场景 | 通过条件 |
|---|---|---|
| A1 | 编辑、分屏左侧、分屏右侧、预览四处分别框选 | 工具栏均在选区下方弹出，项目与顺序正确；滚动跟随、滚出隐藏 |
| A1b | 添加评论 | 工具栏最左侧为添加评论按钮；点击后工具栏消失，现有评论框打开在选区段落后并聚焦，发表后锚点与评论卡片出现；编辑与预览视图都可用 |
| A2 | 「⋯」菜单 | 列出六项，点击各自直接执行 |

## 9. 待用户确认

1. **范围**：是否只在作品正文中提供（本设计），还是大纲、设定等所有 Markdown 编辑器也要？
2. **续写的替换方式**：设计为“原文 + 续写”写回，原文不丢。若希望续写结果真的替换掉选中原文，请说明。
3. **总结的替换方式**：总结替换后正文会变成一段概括，一般用于写章节摘要草稿。是否保留「替换」，还是总结只提供「复制」？设计稿按需求保留「替换」。
4. **标准/计划模式**：对话输入框有「标准/计划模式」，单段修改用不到，设计中去掉。需要保留请说明。
5. **原有「添加评论」浮钮**：工具栏已带添加评论，正文左侧原有的选区「添加评论」圆钮会与之重复。建议框选时隐藏原选区圆钮，保留段落悬停评论钮和行号槽评论钮；也可以两者都保留。设计稿中未画原圆钮。
